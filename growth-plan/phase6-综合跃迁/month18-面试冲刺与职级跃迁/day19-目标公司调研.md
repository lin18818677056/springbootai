# Day 19 · 目标公司调研

> **今日目标**：从"海投"升级为"精准狙击"——建立 ≥10 家目标公司清单（README 验收标准），每家完成"四查"调研，按匹配度分梯队排投递顺序。
> **时长**：调研 2h / 清单 1.5h / 输出 0.5h
> **今日产出**：目标公司清单 ≥10 家（四查档案+梯队划分）+ 每家的 JD 对齐卡

## 1. 知识地图（先讲人话）

```
为什么不能海投（先讲人话）：
  海投像撒网捕鱼——网撒得越广，捞上来越多"不对口的鱼"，
  耗尽你最宝贵的资源：面试状态和精神电量。
  面试状态是消耗品：一周打 5 场，第 5 场的你是残血的；
  精准投递像钓鱼——选好塘、配好饵、一条条钓。

"四查"调研法（每家 20 分钟，查四样）：
  ① 查业务：公司靠什么赚钱？这个岗位的业务线
    是赚钱引擎还是成本中心？
    （成本中心的团队=裁员先裁、涨薪靠后——重要情报）
  ② 查技术：技术博客/开源项目/GitHub/技术大会分享——
    他们的技术栈和你的弹药匹配度多少？
    （面试官的问题往往从他们生产环境长出来——
     查技术栈=预判考题范围）
  ③ 查口碑：脉脉/看准网/知乎——真实评价里的
    高频词是什么？
    （注意去噪：过滤情绪化评价，找"具体事实"：
     "绩效强制分布"是事实，"垃圾公司"是情绪）
  ④ 查面试：牛客/面经网站——近 3 个月这个岗位的
    面经，高频题是什么？
    （直接进你的最后冲刺题单——面经是真题库）

梯队划分（投递顺序=作战序列）：
  T1 冲刺区（2~3 家）：最想去+匹配度最高——但先别投！
    （用 T2 练手，状态最好时打 T1）
  T2 练手区（4~5 家）：匹配度中上——第一批投，
    当"热身赛"，挂了不心疼还能攒面经
  T3 保底区（3 家）：大概率能拿 offer——穿插投递，
    保住"手里有 offer 心不慌"的谈判地位
  ——顺序逻辑：T3、T2 先投，T1 等 T2 打出状态再投。
    这和秒杀系统"预热再放量"是同一个节奏控制
```

## 3. 动手实操（建清单+填档案）

### 3.1 演练一：10 家清单建档（模板直接用）

```
每家一张档案卡（模板）：
  ┌─ 公司：____（业务线：____）
  │ 四查：
  │ ① 业务：赚钱模式____ / 岗位所在线：引擎 or 成本中心？
  │ ② 技术：技术栈____ / 和我弹药匹配点：____
  │    （如：他们博客在推 LangChain4j → 我的 M15 弹药对口）
  │ ③ 口碑：高频词____ / 红旗项：____
  │ ④ 面经：高频题 TOP3：____（直接进冲刺题单）
  │ 梯队：T1/T2/T3
  │ 内推渠道：____（LinkedIn/前同事/技术群）
  │ JD 对齐分：____（day03 的表格直接算）
  └─ 投递窗口：W____（按梯队排）

清单的三个一致性检查：
  ① T1 的 JD 对齐分必须 ≥80（最高目标要最高匹配）
  ② 每家必须有内推渠道（裸投通过率低一档——
    没有渠道的写" LinkedIn 找该团队工程师"行动计划）
  ③ 10 家里至少 2 家"AI 应用岗"（你的差异化弹药
    值钱的地方——别全挤纯传统后端赛道）
```

### 3.2 演练二：面经反哺冲刺题单

```
把四查里的面经高频题汇总（预计 20~30 题）：
  和已有题库（day04~06 的 60 题）对照：
  重合题 → 标"已备"（增强信心：看，押中了）
  新题 → 进《冲刺题单 v2》按"一天最多补 5 题"消化
  特别注意 AI 岗的面经：
    高频题模式："介绍一下你的 AI 项目"（day06 三讲稿）
    + "RAG/Agent 原理"（M14/15）+ "幻觉治理"（day11）
    ——你的主场题库覆盖率应该最高，信心来源
```

### 3.3 演练三：内推渠道激活计划

```
渠道盘点（按有效性排序）：
  ① 熟人内推：前同事/同学/技术群友（有效性最高）
    ——今天发出消息模板：
    "哥，我在看机会，看到贵司 XX 岗位很匹配，
     方便内推吗？简历我发您看看？"
  ② 弱关系激活：LinkedIn/脉脉上目标团队的工程师
    ——话术（不要一上来就要内推）：
    "看了您在 XX 技术大会的分享，关于 XX 的实践
     很受启发。我也在做类似方向（一句话+一个数字），
     方便交流吗？"
    ——先建立技术对话，一周后再提内推
  ③ 技术社区渠道：GitHub 互动过的/博客读者
  纪律：每家 T1/T2 公司至少激活一条渠道再投递
    （裸投是最后手段）
```

### 3.4 思考题

为什么 T1 冲刺区"先别投"反而是最高效的投递策略？（提示：投递的产出不只是 offer，还有"面试表现"这个中间产物——而表现和状态强相关。前几场面试你的六步法可能还在"能走"水平，打好 T2 练手区后它进化到"自动走"，此时打 T1，同样的实力呈现出的效果高一档。反之，用 T1 首秀翻车，还会损失这家公司的"首因印象"（很多公司半年内不给二面机会）。排队不是拖延，是把最好的状态留给最重要的战场——和压测"先小流量预热再全量"同构。）

## 4. 面试连接

**Q：你为什么选择我们公司？（必考题，用四查弹药答）**
> 三个层面的原因。业务上，我调研了你们的业务结构，这个岗位所在的线是公司的核心增长引擎——我加入核心引擎团队比待在成熟业务更能放大我的经验；技术上，我看了你们技术博客里关于高并发网关和 AI 落地的几篇分享，和我们做过的方向高度契合——比如你们提到的问题我在自己项目里踩过并解决过（举一个具体点，如"限流的两层架构"）；个人上，我现在的积累到了"需要一个更大场景验证"的阶段，贵司的规模和工程环境正是我要找的。（→三层递进+具体证据，和"贵司是大平台"这种空话拉开差距）

**Q：你还面了哪些公司？（进度摸底题，答法有讲究）**
> 我在看机会，也在和几家方向相近的公司交流，主要集中在高并发后端和 AI 应用两个方向——和贵司这类岗位同赛道。我的策略是慢投精面：比起数量，我更看重岗位匹配度和团队技术氛围，所以每一家我都是认真调研后才投的。目前流程都还在进行中，我也会根据每家的进展同步。（→诚实+不透露具体名单（防压价）+展示"我在挑你们"的姿态——这个信息差对 day22 谈薪有直接价值）

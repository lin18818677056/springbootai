# Day 23 · 谈薪话术演练

> **今日目标**：把昨天的十问应答表从"纸上"练到"嘴上"——三场角色扮演演练（顺局/压价局/僵局），每场录音复盘；产出《offer 沟通话术卡》随身版。
> **时长**：演练 2h / 复盘 1.5h / 输出 0.5h
> **今日产出**：三场谈判录音 + 话术卡定版 + 心态预案

## 1. 知识地图（先讲人话）

```
为什么谈薪要"练嘴"而不只是"想清楚"（先讲人话）：
  谈判和面试一样，是"临场发挥"型技能——
  纸上写好的话，实战压力下嘴巴会打结；
  打结的瞬间你会脱口而出"行，可以"
  ——这三个字可能值 5 万块。
  所以用练面试的方法练谈薪：角色扮演+录音+复盘。

三种典型局（今天各演一场）：
  顺局：offer ≥ 目标价，HR 追问"还有什么要求？"
    ——最大风险是"贪"，话术见 3.1
  压价局：offer < 目标价，HR 说"预算就这样"
    ——用三步话术（确认-重组-推进），见 3.2
  僵局：双方都不动，HR 说"那就这样吧"
    ——分辨真僵局假僵局，见 3.3

谈判中的三个心态锚（比话术更重要）：
  锚一：他们在雇你，不是施舍你
    ——HR 的 KPI 是招到人，你们是合作关系不是敌我
  锚二：沉默是正常工具
    HR 说完价沉默了？不急着填空白——
    "让您考虑一下"是他们的标准动作，你也可以用
  锚三：所有承诺落纸面
    "入职后调薪""明年晋升股票"——
    口头的话像缓存，重启就没了；offer 里的才是落盘
```

## 2. 核心概念（中英对照）

| 英文 | 中文 | 大白话 |
|------|------|--------|
| Role Play | 角色扮演 | 找人（或 AI）演 HR——练临场的唯一办法 |
| Silence Tactic | 沉默战术 | 报价后不说话等对方先动——谁先紧张谁让步 |
| Package Restructure | 结构重组 | 月薪动不了就谈签字费/调薪点/职级——蛋糕切开分 |
| Written Offer | 书面 offer | 一切承诺的最终载体——落纸面前一切皆口头 |
| Emotional Discipline | 情绪纪律 | 谈判桌上的"不上头"：兴奋和被激都会让你做蠢决定 |

## 3. 动手实操（三场角色扮演）

### 3.1 演练一：顺局——"钱给了，人你要不要"（30 分钟）

```
剧本设定：HR 报价 = 目标价×1.05（高于目标），态度热情。
角色 A（你）：接 offer。
角色 B（自己扮演或找朋友演 HR）：热情推进+顺口收尾。

你的应对脚本（练到脱口而出）：
  ① 表达认可："这个数字和我的预期匹配，很有诚意，
    感谢团队的认可。"（先给 HR 交付感——她的 KPI 达成了）
  ② 确认细节（顺局不是闭嘴就签！）：
    "方便发一份书面 offer 吗？我想确认几个细节：
     薪资结构（月薪×几个月、绩效怎么计）、
     职级、试用期条款、签字费和到岗时间。"
    ——顺局里最容易丢的是"细节确认"：
      绩效算法（是乘法还是加减法）、试用期打折
      （试用期 80% 薪资的话，实打实少拿两个月钱）
  ③ 争取缓冲："我 48 小时内给明确答复，
    期间走一下流程（现司交接评估）。"
  ④ 挂电话后的核对（对底线卡）：
    □ ≥ 目标价？→ 意向确认    □ 结构有没有暗坑？
    □ 有没有比价筹码？→ 若另一家也在走流程，
      48 小时刚好同步信息（day24 决策框架的输入）
  ——贪的边界：顺局里只有一件事可以做：
    拿这家的 offer 去催另一家（"有 offer 在手，
    那边流程能加快"）——但不建议回头加价（伤信用）。
```

### 3.2 演练二：压价局——三步话术（30 分钟）

```
剧本设定：HR 报价 = 目标价×0.85（低于目标），
  口头禅"预算就这样，全公司都这标准"。

三步话术（每一句都有功能）：
  第一步·确认（别急着还价）：
    "理解，感谢您直接告诉我预算约束。想确认下，
     这个数字是月薪还是总包口径？职级对应的是？"
    ——确认细节有两个作用：显得专业 + 争取思考时间
  第二步·重组（换个分法）：
    "月薪口径的话，和我期望的差距在 15% 左右。
     我特别想加入贵司，能不能看看几个变通的结构：
     ① 签字费补一部分差距；② 半年绩效评估后
       调薪到目标位（写进 offer）；③ 职级再评估一档？
     如果这三样有一两样可行，月薪这块我可以接受。"
    ——把"总差额"切成三小块，HR 单独批每一块
      都比批总包容易（大决策变成小决策）
  第三步·推进（给台阶+留口子）：
    "如果结构上确实都困难，那这个数字我也需要
     慎重评估——48 小时内给您答复，可以吗？"
    ——不掀桌，不答应，把球拿回自己手里
僵局预防针：
  HR："别家都这个价，你别家去问问。"
  → "我理解这是内部标准。不过我的情况有两个
    例外依据：一是我在 JD 核心要求（AI 工程落地）
    上有现成实战——可以直接上岗省掉半年摸索；
    二是我手上有同区间的 offer 在谈（如实）。
    如果标准真的刚性，我也尊重，那就是匹配问题
    不是谈判问题。"（亮依据+体面收口，不卑不亢）
```

### 3.3 演练三：僵局——真僵假僵分辨（30 分钟）

```
假僵局信号（还有的谈）：
  ① HR 说"我去帮您申请特批"——她在为你跑流程，
    等待+感谢即可
  ② HR 问"除了钱还有别的顾虑吗"——在找继续谈的抓手
  ③ 拖了三天没消息但没发拒信——可能在走审批
    （跟进一次："想跟一下 offer 审批的进度"）
真僵局信号（到此为止）：
  ① 明确说"这是最终数字，没有讨论空间"+不解释
  ② 要求你"当天必须答复"（人为时间压力=谈判大忌，
    对方不尊重流程=入职后也不尊重你）
  ③ 连结构重组的选项都全部拒绝且无解释
真僵局的处理：
  "感谢您的坦诚。坦白说这个数字和我的预期有差距，
   我会认真考虑，也祝团队招聘顺利。"
  ——walk away 话术的核心：不抱怨、不嘲讽、留后路
    （市场是圆的，半年后 HR 手里可能又冒出新坑）
  然后执行 BATNA：另一家 offer / 留在现司，
  这就是 day22 情报表里 T3 保底的意义——
  有退路的人才谈得了判，没退路的叫求饶。
```

### 3.4 思考题

为什么压价局的第二步是"切蛋糕"而不是"继续要价"？（提示：心理账户原理——对 HR 来说，"月薪加 15%"是一个要惊动老板的大决策，而"签字费批 3 万"和"半年调薪评估"是她权限内或流程内的小决策。你的目标不是"赢得辩论"，是"让对方容易说 yes"——把一个大请求拆成几个小请求，每个小请求都长在对方的流程轨道上，成交概率指数级上升。这和系统设计里"把大事务拆成小事务分步提交"是同一个智慧：不要考验系统的单点承载，要顺着系统的结构走。）

## 4. 面试连接

**Q：（终极实战剧本——从 offer 电话到签字的完整话术链，背熟）**
> 接电话："感谢认可，这个方向和数字都很有诚意。几个细节想确认：薪资结构、职级、试用期条款和签字费，方便展开说下吗？"
> （记录后）"我 48 小时内给明确答复，因为我手上还有流程在走，想对双方都负责。"
> （数字低于目标时，48 小时内回电）"想跟您再聊一次。整体 package 我很认可，唯一差距在 X。我理解预算刚性，所以想提三个结构上的变通：签字费/半年调薪评估点写进 offer/职级再评估。这三样有一两样可行，我今天就定下来。"（给即时成交奖励：你让一步，我立刻签——谈判里的"现在成交"激励）
> （全被拒且是真僵局）"感谢您的坦诚和这些天的沟通，我认真评估后会尽快答复。"
> ——整条链的设计原则：每一步都让 HR 好做事（她的 KPI 是成单），每一步都把决策权留在自己手里（48 小时缓冲），每一步都不烧桥（市场是圆的）。

**Q：谈薪时最忌讳的三件事是什么？（元问题，考谈判素养）**
> 第一忌：情绪化——被压价就上头（"你们这是瞧不起人"）或者被高 offer 冲昏头当场答应，两种都是情绪替你做了决定；第二忌：虚张声势——编一个不存在的竞对 offer 施压，背调一穿帮，offer 直接飞（诚实在这里同样是唯一策略）；第三忌：只看月薪不看结构——15 薪和 13 薪差 15%，绩效是乘法还是加减差更多，股票期权要问清归属期。我的准备是把这三忌反向变成三备：备数据（情报表）、备结构（重组选项）、备退路（BATNA）——谈判桌上的底气从来不是嗓门，是准备。

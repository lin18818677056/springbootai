# Day 22 · 谈薪准备与策略表

> **今日目标**：谈薪是信息战+心理战——今天建三样东西：薪资情报表、个人底线卡、策略应答表；把"不好意思谈钱"变成"有数据地谈钱"。
> **时长**：情报 1.5h / 策略 2h / 输出 0.5h
> **今日产出**：薪资情报表 + 底线卡 + 十问应答表

## 1. 知识地图（先讲人话）

```
谈薪的本质（先讲人话）：
  不是"讨价还价"，是"价格发现"——
  你和公司在互相摸对方的价格区间，
  谁的信息更全、谁的心理更稳，谁拿到中间偏上的位置。
  类比卖房：挂牌前先看同小区成交价（情报），
  定一个"心理底价+理想价"（底线卡），
  中介砍价时有标准话术（策略表）——
  从不裸奔上谈判桌。

谈薪的四个时间窗口（每个窗口打法不同）：
  窗口 1·简历/网申表"期望薪资"栏：
    填"面议"或区间（宽区间下限=你的底线×1.1）
  窗口 2·HR 初聊："您期望多少？"
    反问句式："想先了解贵司这个岗位的预算范围？"
    （先让对方出牌——HR 有预算区间，你不先亮底）
  窗口 3·offer 沟通：核心谈判窗口（明天 day23 专练）
  窗口 4·多 offer 比价：筹码最多的时候（day24 决策）

三个必须知道的行情规则：
  规则一：薪资结构比总数重要
    月薪×几 + 绩效 + 股票/期权 + 签字费 + 五险一金基数
    ——"总包 50 万"可能是 15 薪也可能 13 薪+浮动绩效，
      差别巨大；谈之前先问清结构
  规则二：涨幅锚点
    跳槽涨幅 20%~30% 是市场常态（持平=跳槽无意义，
    50%+ 要有硬理由：职级跳/稀缺技能）
  规则三：先出牌者吃亏？
    未必——但有预算信息时让对方先出牌；
    对方坚持让你先报，报"区间"不报"点"，
    区间下限=你的理想价（锚定效应：锚点上移，全线上移）
```

## 2. 核心概念（中英对照）

| 英文 | 中文 | 大白话 |
|------|------|--------|
| Total Package | 总包 | 现金+股票+福利的全部价值——别只盯月薪 |
| BATNA | 最佳替代方案 | "谈不成我还有 B 公司 offer"——你敢 walk away 的底气（day24 展开） |
| Anchoring | 锚定效应 | 第一个数字会拽着整场谈判走——报区间就是抢锚 |
| Pay Band | 薪资带宽 | 每个职级有个范围——你的目标是带宽中上位 |
| Sign-on Bonus | 签字费 | 一次性签约奖金——月薪谈不动时的补偿性筹码 |

## 3. 动手实操（三件套制作）

### 3.1 演练一：薪资情报表（信息战的主战场）

```
三渠道交叉验证目标岗位薪资（每渠道记一列）：
  渠道 1：看准网/OfferShow 的同岗位晒价（样本 ≥5 条，
    剔除最高最低取中位）
  渠道 2：脉脉/同行朋友打听（问"这个级别的预算范围"
    而不是"你能拿多少"——问范围没人反感）
  渠道 3：招聘软件上同岗位的公开区间（下限≈底线，
    上限≈天花板）

情报表（每家 T1/T2 公司一行）：
  公司 | 岗位 | 渠道 1 中位 | 渠道 2 范围 | 渠道 3 区间
  | 综合判断值 | 我的报价区间
  综合判断值 = 三渠道的加权中位（判断值×0.9 ~ ×1.15
    = 你的报价区间）

别忘了一手情报：自己的现薪要算清（这是涨幅的基数）：
  现月薪 × 月数 + 绩效均值 + 补贴 + （股票折现）
  = 现总包 ____ 万（这个数字必须脱口而出，HR 必问）
```

### 3.2 演练二：个人底线卡（心理战的压舱石）

```
一张巴掌大的卡，三个数字+三条纪律：
  ┌──────────────────────────┐
  │ 理想价：综合判断值 × 1.15（开价锚点）      │
  │ 目标价：综合判断值 × 1.0（满意成交线）     │
  │ 底线价：综合判断值 × 0.85 或现薪+20%（取高者）│
  │  ——低于底线直接礼貌拒绝（BATNA 兜底）      │
  ├──────────────────────────┤
  │ 三条纪律：                                │
  │ ① 不当场答应（"请给我 48 小时考虑"——       │
  │   缓冲期是合法权利，冲动答应=放弃谈判）      │
  │ ② 不先亮底线（底线只写在自己卡上）          │
  │ ③ 不接受"以后再调"的口头承诺               │
  │  （调薪写进 offer 才算数）                 │
  └──────────────────────────┘
```

### 3.3 演练三：十问应答表（HR 高频题预演）

```
写好十问的应答（明 day23 逐题演练，今天先成文）：
  1"您现在薪资多少？"
    → 如实报现总包（背调会查，别注水）+
      "期望涨幅在市场合理区间"（不给具体 %，留空间）
  2"您的期望薪资是？"
    → 报区间："综合我的经验和市场行情，期望在 X~Y"
      （X=理想价，Y=理想价×1.1——锚点抢高位）
  3"这个期望超出了我们的预算"
    → "理解预算约束。想了解差距主要在月薪还是结构？
      如果月薪有难度，签字费/职级评估/调薪周期
      是否有弹性？"（把蛋糕切开谈，不只盯一块）
  4"您手上还有其他 offer 吗？"
    → 如实说进度+不报具体数字："有家在终面，
      但贵司匹配度最高，优先级最清楚"
  5"我们给到 X，您觉得如何？"
    → X ≥ 目标价："非常符合预期，感谢认可"（痛快接，
      别贪）；X < 目标价：明天 day23 的话术三步
  6"什么时候能到岗？"
    → 给确定日期（交接期就是交接期——拖沓的到岗
      承诺会反噬试用期信誉）
  7"你怎么看加班？"
    → "项目关键期全力投入是我的常态，同时我在意
      效率而非时长"（不立 flag 也不假高潮）
  8"您还有什么想问的？"
    → 问结构："方便介绍下薪资结构吗？绩效怎么评？
      调薪机制？"（问结构=行家信号）
  9"如果我们只能给到 Y（低于底线），您还考虑吗？"
    → 启动 BATNA："这个数字和我的预期差距比较大，
      可能不太适合，感谢您的坦诚"（体面 walk away
      也是谈判力——说得出拒绝，才谈得了价格）
  10"内部有同事做同岗位拿的是 Z，比您高/低"
      （压力测试）
    → "每个人的经验和当下的定价不同，我更希望
      基于我能带来的价值来定——比如……（价值三件事）"
      （把比较拉回价值轨道，不接"攀比"框架）
```

### 3.4 思考题

为什么"不当场答应 offer"是三条纪律之首？（提示：当场答应有三重代价——①放弃了最后的谈判窗口（offer 到手时刻是你筹码的峰值，签完就归零）；②冲动决策没经过"底线卡"校验（兴奋状态下底线会上浮，冷静后才发现接低了）；③向 HR 传递"好谈"信号（下一轮调薪你会同样好谈）。48 小时缓冲的真实作用是"把情绪放掉、让数据说话"：拿着 offer 数字回来对底线卡，超目标价→痛快接，低于目标价→明天 day23 的三步话术上场。谈判桌上最贵的三样东西：信息差、情绪、时间压力——缓冲期直接消灭后两样。）

## 4. 面试连接

**Q：（HR 窗口 2 实战示范——被问期望薪资的完整应对）**
> HR："您的期望薪资是多少？"
> 我："想先了解一下，贵司这个岗位的薪资带宽大概是多少？这样我的期望可以更贴近实际。"（反问抢信息）
> HR 若答："我们有带宽，但还是想听您的期望。"
> 我："好的。综合我在高并发优化和 AI 工程落地上的经验——比如 P99 从 800 压到 480 毫秒、AI 客服解决率 78% 这两块，以及市场同类岗位的行情，我的期望总包在 X 到 Y 之间。具体结构可以基于贵司的带宽再聊。"（锚定+价值绑定+留结构讨论空间）
> ——这段话的三个设计：①先试图拿带宽信息；②报区间不报点，且区间下限=理想价（锚高位）；③每句话绑一个价值证据，让数字有支撑。

**Q：HR 压价说"你现在的薪资才 Z，我们要不到 X"。（常见压力局，示范）**
> "现薪是过去市场对当时的我的定价。这一年我补上了两块能力：高并发系统调优的完整方法论，和 AI 工程落地的实战经验——这两块正是贵司 JD 里的核心要求。贵司招我不是买我过去一年的产出，是买未来三年的产出，定价应该对着'未来的我'而不是'过去的我'。当然，我也理解预算有结构约束——如果月薪确实有难度，签字费、半年后的调薪评估点、或者职级对标，这些是否可以作为组合方案？我对贵司的岗位是很认可的，希望我们能在结构上找到双方都舒服的方案。"（→不接"现薪锚"，重新锚定到"未来价值"+给组合方案台阶——谈判不是零和，是把蛋糕切开重新分）

# Day 16 · 弱点修复日

> **今日目标**：按昨天模拟暴露的弱点清单 v1 集中修复——今天不学新东西，只把旧伤口缝合到"能二次上考场"的程度；傍晚用第二轮小模拟验收。
> **时长**：修复 2.5h / 验收 1h / 输出 0.5h
> **今日产出**：弱点修复台账（每题修复动作+复测结果）+ 验收小模拟录音

## 1. 知识地图（先讲人话）

```
修复日的心法（先讲人话）：
  昨天的模拟是"拍 X 光片"，今天是"手术日"——
  手术室三规矩：
  规矩一：只开清单上的刀
    不顺手学新东西！清单外再有趣的题也不碰——
    修复日的产出是"清单清零"，不是"又多了几页笔记"
  规矩二：每个伤口三步缝合
    ① 回读（对应月度文档，20 分钟上限——不是重学）
    ② 重做（重跑对应实验/重写话术卡）
    ③ 复测（30 分钟后录音重答，✓ 才算缝上）
  规矩三：缝不上就"降级处理"
    某题反复补还是 ×？执行降级策略（见 3.2）——
    面试策略不是全都要满分，是"弱项不致命"

"弱项不致命"的三档处理（面试版的田忌赛马）：
  A 档·强化主场：把最强的一两项练到"面试官问啥都
    能绕回来"——主场作战（多数时间在这）
  B 档·防守标准：中等的题保证"四段模板完整、不出
    硬伤"——不求惊艳求稳
  C 档·诚实边界：真正的弱项提前标注岩层——
    被问到就"承认+路径+演进口"，绝不硬编
  ——资源有限时，A 档加注、B 档保本、C 档止损，
    这是全部面试策略的预算分配逻辑
```

## 2. 核心概念（中英对照）

| 英文 | 中文 | 大白话 |
|------|------|--------|
| Deliberate Practice | 刻意练习 | 只练"刚好够不着的题"——舒适区重复=无效工 |
| Regression Test | 回归测试 | 修完的题 48 小时后必须复测——防"假性修复" |
| Triage | 伤情分诊 | 手术室先分诊再开刀——弱点先排优先级再补 |
| Mitigation | 风险缓解 | 缝不上的伤口不硬缝，装"支架"（话术兜底）保命 |
| Confidence Interval | 置信区间 | 你对每题的把握度要心里有数——面试选题答深答浅靠它 |

## 3. 动手实操（手术日流程）

### 3.1 修复一：清单逐题手术（上午）

```
拿弱点清单 v1（昨天产出），逐题执行三步缝合：
  示范（假设昨天卡了"G1 和 ZGC 怎么选"）：
    ① 回读 M1 day26 收集器对比（20 分钟）：
      G1（Region/混合回收/软实时目标 200ms）vs
      ZGC（着色指针/并发整理/<1ms）——
      选型口径：堆 <32G 且停顿要求 100ms 级 → G1；
      超大堆或极端延迟要求 → ZGC（还要算 CPU 代价）
    ② 重做：把选型口径写成权衡五步格式的话术卡
    ③ 复测：30 分钟后录音重答 → ✓ 记台账
  全天节奏（防过载）：
    上午 3 题 + 下午 2 题（纪律：一天最多 5 题）
    每题之间休息 10 分钟（缝合需要固化时间）
```

### 3.2 修复二：缝不上的伤口降级处理（下午）

```
复测两次仍然 × 的题，启动降级三选一：
  选 1·话术支架（首选）：
    写一段 30 秒的"体面兜底"：
    "这块我的生产经验有限，原理上我知道 X，
    如果您方便，想听听生产上通常怎么做"——
    把雷区变成"求知现场"（面试官多半愿意讲，
    还会觉得你坦诚）
  选 2·主动避让：
    反问环节或自我介绍时，不主动往这个方向引——
    简历上如果写了相关字眼但讲不动，删掉它
    （简历六军规第 3 条：归属诚实——写不动的不写）
  选 3·标记弃权：
    出现在场景题里的弱项，答"我会先确认影响范围，
    这个具体调优我没做过，但排查框架是通用的：
    先看监控…"——框架分拿到，细节分放弃
  三选一后写进《岩层地图》（面试前的最后一张牌：
  哪里绝对不硬碰，一目了然）
```

### 3.3 修复三：傍晚验收小模拟（30 分钟）

```
第二轮小模拟（只考昨天+今天修复的题）：
  从修复台账抽 5 题 + 从昨天 ×○ 题抽 3 题 = 8 题
  限时作答+录音
  验收线：
    ≥6 题 ✓ → 修复生效，明天轮 2 按计划开打
    4~5 题 ✓ → 半生效，明天开打前晨读台账 20 分钟
    ≤3 题 ✓ → 明天上午继续修（轮 2 顺延半天——
      宁可慢不可虚，模拟的价值就在能顺延）
  台账归档：修复台账并入《岩层地图》，
    明天模拟出场配置（day14 定的）更新一版
```

### 3.4 思考题

为什么修复日"缝不上就降级"比"死磕到会"更正确？（提示：面试是限时资源分配问题——你的复习时间是预算，各考点是投资标的。死磕一个难点的边际收益越来越低（第八遍重读 GC 日志教程不会比第三遍多会多少），而同样的时间能把两个 B 档题提到 ✓。更重要的是：面试官对候选人的评价是"短板感知"很弱的（没人全知全能），但对"不懂装懂"极其敏感（红旗信号第一条）。所以把弱项从"硬伤"降级为"坦诚的边界"，是期望值最高的操作。这不是躺平，是把有限的子弹打在能命中分数的靶上。）

## 4. 面试连接

**Q：（修复日话术成品示范——遇到真正的弱项时直接用）**
> 这块我坦白说，生产上的实操经验有限。原理层面我知道大概方向——比如 ZGC 用着色指针实现并发整理，停顿能压到 1ms 以内。但如果真在生产选型，我会先看三个约束：堆大小、延迟目标、CPU 预算，然后做一轮 POC 压测再定，而不是直接拍。您团队现在用的是哪个收集器？当时的选型考量是什么？（→承认+原理+方法+反问四件套：弱项被包装成了"有方法论的坦诚者"，还能收集情报）

**Q：怎么判断一道题该答深还是答浅？（元问题，考自我评估力）**
> 我给自己每类题标了置信度：9 分以上的是主场（性能优化、AI 工程），我会主动往这里引，答到 L3~L4 追问深度；6~8 分的是防守区（并发、Redis 原理），四段模板完整即收，不主动加深；6 分以下的是边界区（比如内核网络调优），我会在岩层处明说"这块我的经验边界在哪"。这个分级不是怯场，是对面试官负责——他要在 60 分钟里判断我的真实能力分布，一个诚实的能力地图比一张全 9 分的假地图对他更有用。

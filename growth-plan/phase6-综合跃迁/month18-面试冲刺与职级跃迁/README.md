# Month 18 · 面试冲刺与职级跃迁（M18）

> **本月一句话**：18 个月的弹药入库完毕，本月装弹上膛——把六个项目、十几张数字卡、五版电梯演讲压缩成一份简历和五轮模拟面试，向着 P8 冲刺。
> **总验收（对照总 README 里程碑 M6）**：简历通过 3 位大厂面试官模拟评审；完成 5 轮模拟面试（3 轮系统设计 + 1 轮技术深挖 + 1 轮架构/管理面）。

## 1. 开场先讲人话：面试是一场"证据的展览"

```
面试的本质（18 个月练到最后才看清）：
  不是考试（没有标准答案），是策展——
  你从 18 个月的素材里挑出最硬的证据，按面试官想听的方式
  展示出来。素材早就有了（六个项目/数字卡/防翻车卡），
  本月只做三件事：挑证据（简历）→ 练展示（模拟面试）→
  定价格（谈薪）。

M17 交接卡（上月的两笔账，day01 开箱）：
  ① 18 个月六个项目怎么浓缩成简历上的 6 条 STAR？
    → day01 弹药盘点 + day02 STAR 改写
    （每条一句背景+一个动作+一个数字，数字卡是弹药库）
  ② 管理面必问"你带过几个人"——没真带过怎么答不心虚？
    → day18 架构管理面专项
    （诚实口径："主导设计+小范围推行+系统演练"+证据链：
      模板/评分表/协作规则——心虚来自模糊，诚实来自边界清晰）

本月心法三句：
  ① 简历上的每个字都要经得起三层追问（面试官必杀技）
  ② 面试是双向选择——你在评估他们，不是在求他们
  ③ offer 是谈出来的不是等出来的——价值先于价格
```

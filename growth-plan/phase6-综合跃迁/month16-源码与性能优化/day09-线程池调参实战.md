# Day 09 · 线程池调参实战：别背公式，看仪表盘

> **今日目标**：搞懂经验公式的适用边界；学会"运行时动态调参"这个救命技能；给 Agent 工具线程池做一次实战调参。
> **时长**：理论 1h / 实操 1.5h / 输出 0.5h
> **今日产出**：工具线程池调参记录（before/after）+ 动态调参实验

## 1. 知识地图（先讲人话）

```
经验公式（只是起点，不是答案）：
  CPU 密集型（算数/压缩/序列化）：线程数 ≈ CPU 核数 + 1
    （人多没用——CPU 就那么几个灶台，人多了全在挤厨房）
  IO 密集型（查库/调接口/等模型）：线程数 ≈ 核数 × (1 + 等待/计算比)
    （等的时候别占着灶台，多招几个人轮着用）
  例：8 核机器，任务 90% 时间在等 IO → 8 × (1+9) = 80 个线程

  ⚠️ 公式的坑：等待比是拍脑袋的；上下文切换成本没算；
  还有内存和下游承受力没算。公式 = 初始值，压测 = 裁判。

比调参更重要的三件事（池子不是调出来的，是量出来的）：
  ① 先有仪表盘：活跃线程数 / 队列长度 / 拒绝次数（没有这三样
     一切调参都是玄学）
  ② 再有压测：调参前压一遍，调参后压一遍，只动一个变量
  ③ 最后有台账：写下来为什么调、调了多少、效果如何

动态调参（运行时改参数，不用重启！）：
  pool.setCorePoolSize(n) / pool.setMaximumPoolSize(m)
  JDK 原生支持，改完立即生效——原理是内部重设 + 唤醒/裁剪工人
  用途：大促前临时扩容 / 线上出问题时紧急降压（不重启服务）
  配合配置中心（Nacos）= "线程池热更新"，大厂标配
```

## 2. 核心概念（中英对照）

| 英文 | 中文 | 大白话 |
|------|------|--------|
| Little's Law | 利特尔法则 | 排队系统铁律：并发数 = 到达率 × 停留时间 |
| Dynamic Tuning | 动态调参 | 运行中改池子参数，立即生效不重启 |
| Context Switch | 上下文切换 | CPU 换人干活（有成本，线程多了切换吃掉收益） |
| Queue Depth | 队列深度 | 等位区排了多少人——持续增长的红色警报 |

> **利特尔法则必须会**（一句话版）：系统里平均同时有多少请求 = 每秒来多少 × 每个待多久。例：每秒来 50 个请求、每个待 200ms → 平均同时在跑 10 个。它反过来告诉你"目标延迟下需要多少线程"，比经验公式更有依据。

## 3. 动手实操

### 3.1 动态调参实验（亲眼看见生效）

```java
ThreadPoolExecutor pool = new ThreadPoolExecutor(
        2, 4, 60, TimeUnit.SECONDS,
        new ArrayBlockingQueue<>(100), r -> new Thread(r, "tool-worker"));
// 先往里灌任务
for (int i = 0; i < 50; i++) pool.submit(() -> Thread.sleep(500));

System.out.println("改前 core=" + pool.getCorePoolSize());   // 2
pool.setCorePoolSize(8);          // 运行时扩编！
pool.setMaximumPoolSize(16);
System.out.println("改后 core=" + pool.getCorePoolSize());   // 8
// 观察：新任务立刻被更多线程并行接走，队列消化变快
// 再试试收缩：pool.setCorePoolSize(2) → 多余核心线程空闲后逐渐退出
```

## 4. 面试连接

**Q：线程池参数怎么配？**
> 我不直接背公式。先用利特尔法则从"目标吞吐 × 单次耗时"算出理论并发需求，公式只做初值；然后压测分档验证（一次只动一个变量），盯着活跃线程数、队列深度、P99 三样找最优档位。关键是我能说清"为什么不配更大"——下游承受力和上下文切换都是成本。

**Q：生产上想改线程池参数怎么办？**
> 不用重启——ThreadPoolExecutor 的 setCorePoolSize/setMaximumPoolSize 运行时立即生效。我会配合配置中心做"热更新"，并且必须有监控三件套（活跃数/队列深/拒绝数）先看着，改完观察再决定继续还是回调。这套我在工具线程池上实操过：4→8 线程，P99 降了约一半。

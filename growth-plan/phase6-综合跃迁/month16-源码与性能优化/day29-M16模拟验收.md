# Day 29 · M16 模拟验收：五轮 30 问

> **今日目标**：闭卷口头验收本月 30 天。五轮共 30 问（每轮对准一周+一轮综合压轴）；白板三件套限时画/写；按 L1~L4 判级定下一步。
> **时长**：问答 2.5h / 白板 0.5h / 输出 0.5h
> **今日产出**：30 问作答记录（✓/○/×）+ 三件套照片 + 判级结论
> **规矩**：M13~M15 同款——说给录音笔，不许看笔记；卡壳标 ○，答错标 ×。

## 1. 验收规则

```
每问 90 秒内开口，先给结论再展开（面试铁律）。
30 问里 ≥24 问流畅 = 过线；白板三件套每件限时 5 分钟。
验收后：○ 和 × 的题翻回对应 day 重读，day30 复盘时二次清账。
```

## 2. 第一轮 · 测量与世界观（W1，6 问）

```
1. 四步法是什么？"复测"格为什么不能空？
   （考官想听：没有复测=不知道有没有用=白干）
2. 平均值什么时候骗人？举数字例子并给 P99 结论。
   （99×50ms+1×9500ms：平均 144 vs P99 9500）
3. JMH 三大骗局？各自对策？
   （预热/死代码消除/常量折叠；返回值消费+参数注入+Fork）
4. 压测三戒律？拐点长什么样？
   （单变量/分档/记环境；吞吐不涨 P99 起飞）
5. 火焰图的平顶和尖顶各说明什么？
   （平顶=忙自己；尖顶=只是路过调了别人）
6. 火焰图为什么看不见同步 IO？你用什么补的？
   （On-CPU vs Off-CPU；Arthas trace 墙钟时间——定罪 saveSync 的故事）
```

## 3. 第二轮 · 并发与异步（W2，6 问）

```
7. execute 三步舞？为什么"先排队后扩人"？
   （新线程比排队贵；无界队列让 max 和拒绝永不触发）
8. ctl 怎么一个 int 存两个信息？
   （高 3 位状态低 29 位数量；CAS 一次改俩）
9. 虚拟线程原理？pinning 的版本历史？
   （栈在堆+用户态调度+阻塞让座；JDK24 JEP491 修复 synchronized，
     JNI 仍坑）
10. 并行工具调用的安全阀？理由？
    （只读才并行，写操作独占；防竞态+性能不绑架安全）
11. CF 和虚拟线程怎么分工？
    （虚拟线程管执行直白性；CF 管超时/合并/降级编排）
12. 异步 trace 三个设计决策？高危数据为什么直写？
    （有界/分级/批量；审批凭证可慢不可丢，崩溃丢队列=审计灾难）
```

## 4. 第三轮 · 内存与存储（W3，6 问）

```
13. 分代假设？对象搬家的完整路线？
    （朝生夕死；Eden→Survivor 轮转→15 岁晋老年代）
14. G1 两大发明？停顿承诺的代价？
    （切格子+停顿预测；目标越小回收越碎吞吐降）
15. Humongous 是什么？我们三板斧怎么治的？
    （≥半格直进老年代；截断源头/RegionSize 兜底/采样减量）
16. Java 为什么会泄漏？四大惯犯？
    （还引用但不使用；静态集合/资源/ThreadLocal/监听器）
17. 排查四步法？支配树怎么用？
    （jstat→dump→MAT Retained+Path to GC Roots→修代码）
18. 一致性采样为什么必要？
    （单会话可回放；独立概率=档案撕碎）
```

## 5. 第四轮 · 工程化（W4，6 问）

```
19. 项目六四条架构决策？各配一句为什么。
    （锁定模型外/并行安全阀/异步分级/存储可回放）
20. 台账四格是什么？举例讲一条完整台账。
    （基线/归因/改造/复测；推荐讲工具并行行）
21. 感知延迟和实际延迟的区别？流式帧怎么做的？
    （外卖 App 已接单；thinking/tool/answer 三帧+TTFT 数字）
22. 全链路压测报告五段式？为什么单点数字不能相加？
    （环境/基线/结果/结论/遗留；阿姆达尔+资源竞争+长尾不同步）
23. 演习挖出的真 bug？"保险丝没接电"什么教训？
    （queueWatermark 注入漏了降级空转；预案要实弹验证）
24. 防回潮两层防线？评审四连问是哪四问？
    （看板+卡点；远程调用/大对象/有界/池参数）
```

## 6. 第五轮 · 综合压轴（6 问）

```
25. 项目六从 0 到 1 讲 3 分钟（结论先行，五段式）。
26. 讲一条完整的"测量→改造→复测"台账行（推荐工具并行行：
    400→220ms，含安全阀细节）。
27. 这个项目和你 M13~M15 的项目什么关系？
    （性能专项治理 M15 项目五；台账/点火/日报/降级全部是老配方
     的新场景——同构视角）
28. "最坏损失"式自答：这次优化最大的风险是什么？
    （参考：并行引入的资源竞争/异步丢数据/采样漏关键 trace——
     各配防御：安全阀/分级直写/一致性采样+错误全存）
29. 流量再涨 10 倍，哪里先崩？
    （Ollama 单卡排队→多实例+分级路由；热区表膨胀→提前分层；
     连接池瓶颈→池监控+扩容——能主动推演=加分项）
30. 这个月你最大的一个"诚实认知"是什么？
    （参考方向：优化最大的敌人是"感觉"——三个白干实验教会
     我只信测量；或"优化是持续运营不是一次性运动"）
```

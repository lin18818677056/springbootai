## 1. 六天串讲（一条线讲下来）

```
day08 线程池源码：execute 三步舞（核心→队列→临时工→拒绝）
  → 反直觉点：先排队再扩人；无界队列让 max 和拒绝策略全部失效
  → ctl 一个 int 存状态+数量
day09 调参实战：公式只是初值（利特尔法则推并发需求）
  → 动态调参 setCorePoolSize 热更新 → 工具池 4/8/16 三档压测
day10 虚拟线程：专车司机 vs 共享单车
  → 阻塞时 unmount 让座；pinning 历史坑（JDK24 已修，JNI 仍坑）
  → 千任务实验：200 池 1 秒 vs 虚拟 200ms
day11 并行工具调用：交接卡①落地
  → 只读并行/写操作独占（安全阀）→ 双工具 400ms→220ms
day12 CF 编排：取餐凭证 + 超时刹车 + 降级兜底
  → 虚拟线程管执行、CF 管编排（不二选一）
day13 trace 异步写入：交接卡②前半落地
  → 丢小票+记账员批量录入；高危直写（可慢不可丢）
  → 主链路增量 45ms→<1ms
```

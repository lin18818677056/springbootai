# Day 10 · 风险管理：风险登记表与坏消息上浮

> **今日目标**：掌握"风险≠问题"的区别；学会用风险登记表管理项目不确定性；练习"坏消息主动上浮"的话术与节奏——把暴露风险从"怕挨骂"变成"职业习惯"。
> **时长**：理论 1h / 演练 1.5h / 输出 0.5h
> **今日产出**：项目七风险登记表（5 条风险全流程管理）+ 上浮节奏卡

## 1. 知识地图（先讲人话）

```
风险 vs 问题（一字之差，管理方式完全不同）：
  问题 = 已经发生的坏事（着火了，灭火）
  风险 = 还没发生但可能发生的坏事（闻到煤气味，先关阀）
  类比体检：问题=确诊生病；风险=指标偏高——
    高明的人管风险（便宜），糟糕的项目管问题（昂贵）。

风险的四个属性（登记表四列）：
  描述：什么事可能发生（具体，不写"可能有风险"这种废话）
  概率 × 影响 = 等级（高中低，两维打分）
  应对：四种姿势选一种——
      规避（不干了）/ 转移（外包/保险）/ 减轻（降概率降影响）/ 接受（记账盯着）
  触发信号：什么迹象出现说明风险正在变成问题（这是新手最漏的一列！）

坏消息上浮的心法（本月心法③展开）：
  好消息从下往上会缩水，坏消息从下往上会蒸发——
    每一层都不想当坏消息的传达者，到老板耳朵里已经晚了。
  所以职业的做法：坏消息我亲自送、提前送、带方案送。
  老板最恨的不是坏消息，是"你怎么现在才说"。
```

## 2. 核心概念（中英对照）

| 英文 | 中文 | 大白话 |
|------|------|--------|
| Risk Register | 风险登记表 | 项目的"体检报告"：列出所有可能的病+预防措施 |
| Mitigation | 风险减轻 | 降低概率或影响（系安全带不是不开车） |
| Trigger | 触发信号 | 风险转问题的前兆指标（煤气味=泄漏的前兆） |
| Contingency Plan | 应急预案 | 风险真发生时的既定动作（不现想办法，照单执行） |
| Escalation | 上浮/上报 | 超出自己权限或承受力的风险，主动交给能处理的人 |

## 3. 动手实操（演练）

### 3.1 演练一：给项目七做风险登记表

```
项目七 = 项目六性能优化包装成"团队推广项目"（day22 展开）。
提前做 5 条风险（示范含全部四列）：

| 风险描述                     | 概率 | 影响 | 应对      | 触发信号         |
|------------------------------|------|------|-----------|------------------|
| 快递 API 审批延迟（day08 遗留）| 中   | 中   | 减轻：模拟数据先行 | 审批超 3 天未过  |
| 团队推广规范遭抵触（day17 埋） | 高   | 中   | 减轻：试点先行+工具卡点 | 试点组消极使用 |
| 压测环境长期抢不到           | 中   | 高   | 规避：申请专属时段 | 两次预约失败     |
| 模型版本升级导致工具格式漂移   | 低   | 高   | 转移：版本锁定+回归考卷 | 考卷正确率跌破 90% |
| trace 磁盘增长超预期          | 低   | 中   | 接受：日报盯曲线（M15 六指标） | 周环比 +30% |

自检要点：每条都有"触发信号"吗？没有触发的应对是空话。
```

### 3.2 演练二：坏消息上浮话术与节奏

```
上浮节奏卡（什么时候说什么话）：
  黄灯（刚闻到味）："提个醒：X 有延期的苗头，我在盯，
    周五前给结论。"——一句带过，不上纲上线
  橙灯（触发信号出现）："X 的触发条件出现了（具体说信号），
    影响：可能延 2 天。我有 A/B 两个方案，建议 A，需要您拍板。"
  红灯（已成问题）："X 确认延期 2 天（已成事实），
    补救方案已启动：……。复盘时我会给预防方案。"
  三层共同点：都有"影响+时间点+我的动作"——
    上浮不是甩锅，是"我知道了、我管着、这些事需要您知道"。

演练：把 day08 的快递 API 预警按黄/橙/红三层各说一遍（录音）。
```

### 3.3 演练三：AI 陪练"报喜不报忧的诱惑"

```
让 AI 扮演"听说坏消息就骂人的暴怒老板"：
  你按橙灯话术报告 → AI 老板发火 → 你练习：
  ① 不接情绪接事实："您先看这个数字和影响范围"
  ② 展示掌控感："触发后我已启动预案，这是执行清单"
  ③ 给决策点："现在需要您定的只有一件事：是否通知业务方"
  录音复盘：老板发火时你是否慌到语无伦次？
  （管理面试常见压力题：考的就是这个肌肉）
```

### 3.4 思考题

为什么风险登记表里"触发信号"比"应对措施"更重要？（提示：应对措施只有触发信号亮了才需要执行——没有信号的应对永远躺在表格里；有信号你才知道"现在是该动手的时候了"。信号把静态表格变成动态雷达。）

## 4. 面试连接

**Q：讲一个你管理风险的例子。**
> 项目七推广期我列了 5 条风险，举一条：模型版本升级可能导致工具调用格式漂移，概率低但影响高。应对是版本锁定+回归考卷（M15 的 20 题工具考卷直接复用），触发信号设为"考卷正确率跌破 90%"。这个例子的要点是：每条风险都有量化的触发信号，不是"我盯着"这种空话——有信号，风险才从纸面变成雷达。

**Q：坏消息你会立刻上报吗？**
> 会，但分层。刚有苗头时一句话提醒（黄灯），触发信号出现时带影响和方案上报（橙灯），已成事实时带补救方案汇报（红灯）。三层都有"影响+时间点+我的动作"。我的原则是：老板可以接受坏消息，不能接受"怎么现在才说"——提前暴露是风险管理，隐瞒到最后是事故。

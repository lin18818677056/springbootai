# Day 05 · 会议工程：把开会当成本账来算

> **今日目标**：学会用"每小时多少钱"的视角看待会议——识别无效会议的四个特征；掌握三种会议的标准化流程（短会/复盘会/评审会）；给自己算一笔月度会议成本账。
> **时长**：理论 0.5h / 演练 1.5h / 输出 0.5h
> **今日产出**：会议成本账 + 复盘会主持词模板 + 无效会议诊断记录

## 1. 知识地图（先讲人话）

```
开会的真相：一场 8 人参加 1 小时的会 = 烧掉 8 个人时。
按 Java 工程师全成本 150 元/小时算 = 1200 元一场。
    ↓ 类比
每次点"发送会议邀请"前，想象自己在点点外卖：
  8 人份 × 1 小时 = 1200 元的一单外卖，值不值？

无效会议四个特征（中两条就该砍）：
  ① 没有议程：开会前说不清楚要决定什么
  ② 该对齐的开成了讨论：5 个人的事拉了 15 人围观
  ③ 只讨论不决策：散会时没人知道"谁、何时、做什么"
  ④ 本可异步：一句话/一个文档能解决的，非要开会

三种会议的标准姿势：
  短会（≤30min）：议程先行 → 只拉决策相关人 → 散会必出行动项
  复盘会：对事不对人 → 数据说话 → 产出可执行改进项（不超过 3 条）
  评审会：材料提前发 → 会前收集意见 → 会上只谈分歧（day15 展开）
```

## 2. 核心概念（中英对照）

| 英文 | 中文 | 大白话 |
|------|------|--------|
| Agenda | 议程 | 开会前写好的"菜单"：议什么、谁来讲、要什么结论 |
| Action Item | 行动项 | 散会时确认的"谁在什么时候干什么"，没有行动项的会等于白开 |
| Retrospective | 复盘会 | 对照目标看结果：哪里好保持、哪里差改进，对事不对人 |
| Decision Log | 决议记录 | 会上拍的板都写下来，防止一周后"当时不是说好了吗" |
| Async First | 异步优先 | 能写文档说清的不开会——开会是最后的手段，不是默认选项 |

## 3. 动手实操（演练）

### 3.1 演练一：算一笔自己的会议成本账

```
模板（贴在自己工位上，每次接受会议邀请前过一遍）：
  会议名：__________  时长：__h  人数：__
  成本 = 人数 × 时长 × 150 元 = ______ 元
  议程有没有提前发？ □有 □没有
  预期产出什么决议？ __________
  我必须到场吗（信息可否会后看纪要）？ □必须 □可以异步

自测：回想上周参加的会议，按这个模板逐个填。
  预期发现：至少 1/3 的会你其实可以不参加或只看纪要。
```

### 3.2 演练二：写一份复盘会主持词（30 分钟版）

```
复盘会主持词模板（照着念就能开）：
  [0-3min] 定调："今天只对事不对人，目的是让下个迭代更顺，
           不是追责。有数据看数据，没数据讲事实。"
  [3-10min] 对目标："本迭代目标是 X，实际完成 Y，
           差距主要在 A/B 两处。"（主持人提前准备好数据）
  [10-22min] 三个问题轮流说（每人 1 分钟，不打断）：
           ① 哪件事做得好，要保持？
           ② 哪件事卡住了，为什么？
           ③ 下个迭代你想改变的一件事？
  [22-28min] 收敛：把大家说的归类，投票选出改进项
           （最多 3 条，多了执行不了）
  [28-30min] 确认行动项："每条改进项有负责人和完成时间，
           我记入决议，下期复盘先对上期的账。"

演练：拿 M14/M15 某周当素材，自己对着手机主持一遍（录音）。
```

### 3.3 演练三：给一场无效会议"开刀"

```
找一场你印象最差的会，写"会议病历"：
  症状：________（对照四个特征勾选）
  病根：________（是没议程？还是人拉多了？还是不敢拍板？）
  处方：________（如果我主持，agenda 怎么写？拉谁？砍谁？）
  复诊标准：下次同类会，怎么判断治好了？

面试价值：这段"会议病历"就是管理面"你怎么提效"的活例子。
```

### 3.4 思考题

老板临时拉会且没有议程，你直接拒绝吗？（提示：管理是影响不是对抗——可以回"为了让会开得高效，我先跟您对一下要决策的点，我提前准备下材料"，把"拒绝"翻译成"帮忙"。）

## 4. 面试连接

**Q：你们团队的会议效率怎么样？你做过什么改进？**
> 我先算过成本账：8 人 1 小时的会就是 1200 元，所以我做了三件事——开会必有议程（提前发，没议程的会我可以婉拒）、只拉决策相关人（围观的人会后看纪要）、散会必有行动项（谁/何时/做什么，记决议）。复盘会我用固定主持词控时，30 分钟必出不超过 3 条改进项。一个月下来我自己的无效会议少了三分之一。

**Q：复盘会怎么避免开成批斗会？**
> 规矩提前定：对事不对人，先看数据再看感受。主持人要带头自我暴露——我先讲自己哪个判断失误了，大家才敢讲真话。另外改进项不超过 3 条，且下期复盘先对上期的账，让大家看到"复盘真的有用"，不是走形式。

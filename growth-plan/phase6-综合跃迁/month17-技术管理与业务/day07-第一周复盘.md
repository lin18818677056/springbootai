> **今日目标**：串讲 day01~06 六天内容；做 W1 体检四项；8 题闭卷自测；留一道 W2 预习思考题。
> **时长**：串讲 1h / 自测 0.5h / 输出 0.5h
> **今日产出**：W1 思维导图 + 自测错题清单

## 1. 六天串讲（先讲人话）

```
day01 从写代码到带队伍：
  球员→教练三种心态转变（产出观/成就感/汇报观）。
  核心一句：管理不是升职是转行——"我的产出=团队产出之和"。
day02 向上汇报金字塔：
  结论先行+三层支撑；老板语言三要素（钱/风险/时间）。
  核心一句：老板的时间以分钟计费，第一句话就是答案。
day03 技术方案写作：
  RFC 按团队可评审标准重写项目六报告（背景/目标/方案对比/
  风险/里程碑五件套）；核心一句：写方案是给"未来很忙的自己"
  和"不看代码的评委"看的。
day04 跨团队协作：
  接口人机制+共识书面化+翻译术（你方系统/我方依赖/各自动作
  各自时间）。核心一句：口头共识等于没共识，拉群截图不算数。
day05 会议工程：
  1200 元一场的成本账；无效会议四特征；复盘会主持词。
  核心一句：没有行动项的会等于白开。
day06 业务理解：
  五指标+业务漏斗+技术→业务翻译表。
  核心一句：技术指标是过程，业务指标是成绩。

W1 一条主线：换脑子——从"把事做完"到"让一群人把事做成，
  并且让老板看得懂、信得过、敢拍板"。
```

## 2. W1 体检四项（诚实自评）

```
① 汇报能力：给我 3 分钟，能把项目六讲得让"老板"点头吗？
  （用 day23 标准预演一次，卡壳即不过）
② 文档能力：重写后的 RFC 让一个不懂项目的朋友读——
  他能复述"你要干什么、为什么这么干"吗？
③ 会议习惯：上周的会议，有没有一场是你主动推动砍掉/缩短的？
④ 业务语言：DAU/GMV/转化/留存/ARPU 五个词能口语化讲吗？
```

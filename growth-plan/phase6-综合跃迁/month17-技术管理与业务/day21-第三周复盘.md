# Day 21 · 第三周复盘：影响力与组织周

> **今日目标**：串讲 day15~20 六天内容；做 W3 体检四项；9 题闭卷自测；留一道 W4 预习思考题。
> **时长**：串讲 1h / 自测 0.5h / 输出 0.5h
> **今日产出**：W3 思维导图 + 自测错题清单

## 1. 六天串讲（先讲人话）

```
day15 主持技术评审：
  会前三件事（材料预发/预收意见/议程写清）+会中三动作
  （破题/控时/收敛）+收敛三技术（表决/试验/升级）+
  会后一邮件。核心一句：评审会的目的是决定，不是讨论。
day16 技术布道与分享：
  15 分钟黄金结构（钩子/问题/三要点/带走项/回收）；
  三次彩排法（对稿/脱稿/掐表 14:30）；QA 诚实兜底。
  核心一句：分享的第一受益人是自己。
day17 规范推广实战（M16 交接卡②兑现）：
  推广三部曲（工具卡点/试点话术/度量指标）；四连问卡点
  三档方案（PR 模板/CI 检查/机器人）；试点数据返工 4→1。
  核心一句：没有卡点的规范等于没有规范。
day18 面试官视角：
  P6 考察矩阵（基础 30/工程 40/协作 20/潜力 10）；
  面试官靠追问辨真假；策略=2~3 个阵地项目深挖到底。
  核心一句：准备面试=把自己的项目追问三层。
day19 技术选型方法论：
  四步（定标/候选/POC/ADR）；分数高≠选它（权重是主人）；
  ADR 要写"什么时候该推翻我"。
  核心一句：选型不是选最好的，是选最适合场景的。
day20 成本账与效率（M16 交接卡①深化）：
  三本账（机器钱/人力钱/机会成本）；人力钱贵一个量级；
  效率杠杆排序（人力>机器>微观性能）；自我纠错的数字才可信。
  核心一句：砍半人天比砍半机器更值钱。

W3 一条主线：让人听你（主持/分享）、信你（规范+数据）、
  跟你（选型+成本账都是"让决策可被说服"的技术）。
```

## 2. W3 体检四项（诚实自评）

```
① 主持肌肉：45 分钟模拟评审三个分歧全收敛了吗？
  哪个收敛技术用得最别扭？（通常是"升级收敛"——
  承认权限边界让人不适，但它是诚实）
② 分享肌肉：第三遍彩排压到 14:30 了吗？口头禅戒了几成？
③ 落地肌肉：四连问的试点话术敢对真人（哪怕家人）说一遍吗？
④ 算账肌肉：AI CFO 的三连追问（ROI/再降/代价）接住了吗？
```

## 3. 九题闭卷自测（对答案不许翻笔记）

```
1. 评审会"会前三件事"是什么？为什么占成败 80%？
2. 收敛三技术分别适用什么分歧？为什么试验收敛优先？
3. 15 分钟分享的黄金结构五段？为什么要点不超过三个？
4. QA 被问倒的标准答案是什么？（诚实+时间点+FAQ 追踪）
5. 推广三部曲对症哪三道关？
6. 卡点三档方案？为什么先轻后重？
7. P6 考察矩阵四块及权重？面试官的"信号"是什么？
8. 选型四步？ADR 五要素？为什么写"可推翻条件"？
9. 三本账是什么？为什么人力钱贵一个量级？
```

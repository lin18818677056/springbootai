# Day 27 · 管理复盘与评分：四场演练的短板清单

> **今日目标**：对四场模拟演练（汇报/评审主持/冲突调解/业务价值）做统一评分与复盘；产出短板清单和补练计划；为 M18 简历库提取"管理素材卡"。
> **时长**：评分 1h / 复盘 1h / 输出 0.5h
> **今日产出**：四场评分总表 + 短板清单与补练计划 + 管理素材卡

## 1. 知识地图（先讲人话）

```
复盘的正确的打开方式（对照本计划一贯原则）：
  评分不是给自己打脸，是给"补练"排优先级——
  分数最低的项=下个月最先练的项。
  诚实传统（M13~M16 延续）：打分宁低勿高——
    高估自己的管理能力，入职第一周就会现形。

四场演练统一评分表（每场 100 分制，录音为证）：
  场次           核心考察              我的分  最弱一处
  汇报（day23）  结构/数字口径/答辩     __    ______
  评审（day24）  控场/收敛/决议        __    ______
  调解（day25）  倾听/翻译/规则化       __    ______
  价值（day26）  翻译/可验证/复述通过   __    ______
  总分与短板排序：______________

复盘三视角（每个演练都过一遍）：
  ① 我视角：哪一步卡壳/超时/说错？（技术层）
  ② 对手视角：AI 的哪个反应说明我说得不好？
    （被打断/追问/不点头的位置）
  ③ 教练视角：如果导师在看，第一句建议会是什么？
    （通常是：语速、结论位置、过早辩解）

管理素材卡（为 M18 简历/面试提取，今天是采矿日）：
  每场演练提取一张卡：一句话场景+一个动作+一个数字
  例：调解卡——"新人老人方案之争升级互告状；四步调解
  （倾听/共同目标/翻译成规则/收敛回访）；三条规则双方
  点头且两周回访零复发。"
```

## 2. 核心概念（中英对照）

| 英文 | 中文 | 大白话 |
|------|------|--------|
| After Action Review | 行动后复盘 | 军方四问法：目标是什么/实际怎样/差距为何/下次怎么改 |
| Skill Matrix | 技能矩阵 | 把能力拆成可打分的细项，短板一目了然 |
| Deliberate Practice | 刻意练习 | 在短板区练习（舒适区练习=娱乐，day21 已埋过这句） |
| Evidence-based | 证据导向 | 自评靠录音/文字记录，不靠"我感觉还行" |
| Feedforward | 前馈 | 复盘不只向后看，还要把教训转成下一步的具体动作 |

## 3. 动手实操（演练）

### 3.1 演练一：四场统一评分

```
回听四场录音，按下表逐项打分（每场五项各 20 分）：
  汇报场：结构清晰 / 数字口径 / 三连问应答 / 时间控制 / Ask 明确
  评审场：破题控时 / 质询质量 / 不当裁判 / 收敛技术 / 决议完整
  调解场：只听不判 / 共同目标 / 翻译完整 / 规则可执行 / 回访机制
  价值场：零术语 / 数字有口径 / 复述通过 / 竞品应答 / 受众切换
打分纪律：每一项的分数必须能在录音里指出对应时间点
  （"2:30 处我说错了口径"）——指不出证据的分数无效。
```

### 3.2 演练二：短板清单与补练计划

```
输出格式（示例，按自己的真实结果填）：
  短板 TOP3（按分数从低到高）：
  ① 调解场·翻译不完整（14/20）：
    漏翻 2 个情绪词（"凭什么"和"凭什么嘛"没接住）
    补练：下周重演一次，情绪词典先备 10 个常见词+翻译模板
  ② 汇报场·超时（16/20）：第一遍 17 分钟
    补练：只练 5 分钟版×3 次，掐表
  ③ 评审场·差点下场吵（16/20）：
    某论点被质疑时我辩了 3 轮
    补练：重看 33'~40' 段，练习"记录+转问"代替"辩解"
补练排期：写进下月 W1 的三个空档（具体到天）。
```

### 3.3 演练三：管理素材卡（M18 采矿）

```
四张卡模板（填完直接进简历素材库）：
  卡 1·汇报：向总监季度汇报 15+10 分钟；金字塔结构+
    三本账+主动交风险；三连问全接住，被追问口径能报出处。
  卡 2·主持：主持物流工具方案评审（聚合 vs 官方之争）；
    定标+Spike 收敛；双方 disagree & commit，决议邮件 24h 发出。
  卡 3·调解：新人老人冲突四级升级（情绪/立场/积怨/交付）；
    四步调解把情绪词翻译成 3 条可执行规则；两周回访零复发。
  卡 4·价值：业务价值说明书一页纸；业务方复述测试通过；
    竞品数字压力下用"对口径"化解并转化为 roadmap。
诚实标注：所有场景为"主导设计+小范围推行+模拟演练"，
  M18 面试时口径保持一致（README 已立的规矩）。
```

### 3.4 思考题

为什么说"分数最低的项=下月最先练的项"而不是"最喜欢的项多练练"？（提示：刻意练习的定义就是"在能力边缘的不适区练习"——喜欢的项目通常是已经会的（练了只有安慰没有成长）；分数低+录音有证据=最诚实的短板地图。管理能力和代码一样：最弱的那个模块决定系统整体上限。）

## 4. 面试连接

**Q：你怎么评估和提升自己的软技能？**
> 和练代码一个套路：量化+刻意练习+复盘。这一个月我把管理动作拆成了四场可打分的演练（汇报/评审/调解/价值说明），每场录音为证、逐项打分，指出证据才算数。结果发现我的短板在"冲突调解的情绪词翻译"——漏翻两个词，下周加练。我不太相信"我沟通能力还行"这种自我感觉，我只信打分表和录音——软技能没有证据的评估都是玄学。

**Q：这一个月演练的成果怎么转化到真实工作？**
> 三个转化：模板直接带走（金字塔汇报/决议邮件/价值说明书/协作规则四件套都是可复用的文档资产）；话术形成肌肉记忆（被追问口径、被业务施压时的应答已经练到不假思索）；诚实的经验边界（我知道自己练到哪一层——主导设计+小范围推行，入职后会从真实场景的一对一沟通开始放大）。

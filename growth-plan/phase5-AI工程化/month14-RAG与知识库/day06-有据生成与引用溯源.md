# Day 06 · 有据生成与引用溯源：让答案带着出处

> **今日目标**：治三大病里最凶的病③（生成幻觉）——Grounding Prompt 写法（照资料答/没有就说不知道）+ 引用溯源（答案带 [1][2] 出处）+ 拒答策略（检索不可靠时宁可闭嘴）。
> **时长**：Prompt 设计 1h / 对照实验 2h / 输出 0.5h
> **今日产出**：《有据生成 Prompt 模板》（模板库⑨号）+ 三版对照实验记录
> **对照教程**：`ai-learning/04-RAG检索增强.md` 第 2 节 + 第 5 节 Faithfulness

## 1. 知识地图（先讲人话）

```
昨天 Q4 的幻觉现场："退款要手续费吗"——资料没写，
  模型自作主张答"需要 5% 手续费"。为什么？
  因为 v0 的 Prompt 只说了"根据以下资料回答"——
  但没说"资料里没有的就直说没有"！模型的接龙天性（M13 day01）：
  用户问了，资料里找不到直接答案，接龙惯性就往下编。

治法三板斧（都是 Prompt 层的，成本为零）：

板斧① Grounding Prompt（有据约束）：
  "只根据下面的资料回答；资料不足以回答时，回答
   '抱歉，知识库中没有相关内容'——禁止自行推测或补充。"
  —— 把"照资料说"从默认行为变成硬性纪律（M13 day11 Constraint 的用法）

板斧② 引用溯源（Citation）：
  资料注入时编号 [1][2][3]，要求答案在关键句后标 [1]。
  好处三连：用户可验证（信任↑）/ 排查方便（答错了知道哪块资料有问题）/
  天然抑制幻觉（要标出处，编的就得掂量）

板斧③ 拒答策略（Refusal）：
  检索分数全线低于阈值（如最高分 < 0.6）→ 说明库里根本没有相关资料
  → 直接走拒答话术，连模型都不用调（省钱+零幻觉风险）
  —— "宁可说不知道，不可一本正经地胡说"（客服场景这是铁律）
```

## 2. 核心概念（中英对照+大白话）

| 英文 | 中文 | 大白话解释 |
|------|------|-----------|
| Grounded Generation | 有据生成 | 答案严格来自资料，资料外内容零容忍 |
| Citation | 引用 | 答案标注出处编号（可点开验证） |
| Refusal | 拒答 | "知识库里没有"——合规且安全的回答 |
| Faithfulness | 忠实度 | 答案忠于资料的程度（day22 的核心指标） |
| Similarity Threshold | 相似度阈值 | 检索分数低于它=资料不可信→拒答 |
| Hallucination | 幻觉 | 资料没有它来编（病③的学名） |

## 3. 动手实操：三版 Prompt 对照实验

### 3.1 三版设计（控制变量，只改 Prompt）

```powershell
# 同样 5 个问题（day05 的记录表原题），只换 Prompt：
# A 版（v0 原版）："根据以下资料回答问题。资料：... 问题：..."
# B 版（+Grounding）：A + "只根据资料回答；资料不足以回答时明确说
#    '知识库中没有相关内容'，禁止推测。"
# C 版（+Grounding+引用）：B + 资料编号注入 + "答案中引用的句子
#    末尾标注 [编号]。"
```

### 3.2 《有据生成 Prompt 模板》（模板库⑨号，最终版长这样）

```
你是客服知识助手。请严格遵守：
1. 只根据 <资料> 标签内的内容回答问题。
2. 答案中的关键结论句末尾标注来源编号，如 [1]。
3. 资料不足以回答时，只回答："抱歉，知识库中暂时没有相关内容，
   已为您转接人工。" —— 禁止推测、禁止补充资料外知识。
4. 资料之间有冲突时，指出冲突并建议人工确认。
<资料>
[1] {chunk_1}
[2] {chunk_2}
[3] {chunk_3}
</资料>
问题：{question}
（注意 <资料> 标签隔离——M13 day13 防注入的手法直接复用：
 用户问题里就算藏"忽略以上指令"，也在标签外，动不了资料区）
```

### 3.3 对照实验记录（填实测）

```
《三版对照表》（5 问 × 3 版，关注 Q4/Q5 两个幻觉雷区）：
  问题            | A 版          | B 版          | C 版
  退款多久到账     | ✓             | ✓             | ✓+标[1]
  退款要手续费吗   | ✗ 编出 5%     | ✓ 说没有       | ✓ 说没有+[1]
  会员积分规则     | ✗ 编          | ✓ 拒答         | ✓ 拒答
  怎么退货        | △ 检索没到     | △ 同左        | △ 同左（病①未治）
预期结论：
  · B 版幻觉消失（Grounding 生效）
  · C 版可验证（引用生效），答案变"有据可查"
  · Q3 照旧差——那是病①检索的锅，Prompt 治不了，W2 上药
  · 拒答率上来了别慌：拒答是安全，胡说是事故（老板问起就这么答）
```

## 4. 面试连接

**Q：怎么保证 RAG 的答案不胡说？（幻觉治理的生成侧标准答案）**
> 生成侧三板斧，全是零成本的 Prompt 工程。第一斧有据约束：Prompt 里硬性规定只根据资料回答，资料不足必须明确说没有，禁止推测——模型的接龙天性是用户问了就往下编，你不明说"可以说不知道"，它就默认要编。第二斧引用溯源：资料注入时编号，要求关键句标引用——好处是用户可验证、排查能定位到具体资料块，而且要标出处本身就在抑制编造。第三斧拒答策略：检索相似度全线低于阈值说明库里没这知识，直接走拒答话术连模型都不调——省钱且零幻觉风险。我们做过三版对照实验，同一批问题，裸 Prompt 版会把不存在的手续费编出来，加上有据约束后幻觉消失，加上引用后每个结论可溯源。当然拒答率升高要接受——我的原则是宁可说不知道，不可一本正经地胡说，客服场景这是事故和安全的分界线。检索侧的漏召是另一码事，靠混合检索和查询改写治，那是本周后半段的故事。

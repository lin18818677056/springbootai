## 1. 知识地图（先讲人话）

```
四步流水线（全是本周学过的零件，今天只做"组装"）：

  ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
  │ ① 切分   │ → │ ② 嵌入   │ → │ ③ 检索   │ → │ ④ 生成   │
  │ day04    │   │ day02    │   │ day03    │   │ M13 手艺 │
  │ 文档→块  │   │ 块→坐标  │   │ 问题→最近 │   │ 照资料答 │
  └─────────┘   └─────────┘   └──的K块──┘   └─────────┘
     （① ② 是入库时做一次；③ ④ 是每次问答都跑）

  查询链路（每次问答）：
  用户问题 → 问题也嵌入成坐标 → 在库里找最近 3 块
  → 拼进 Prompt（"根据以下资料回答"）→ 模型生成 → 返回

类比全程：图书馆查资料。
  ① 把书拆成卡片（切分）② 给每张卡片编目录（嵌入）
  ③ 读者提问→按目录找卡片（检索）④ 抄着卡片写答案（生成）

今天不追效果，只求"通"：能答、答案大体靠谱、全链路每步看得见。
朴素 RAG 三大病（今天故意不治，先得病再吃药）：
  病① 检索不准：换说法的问题找不到（"怎么退货"搜不到"7天无理由"段）
  病② 上下文污染：Top3 里混进无关块，挤占窗口还带偏模型
  病③ 生成幻觉：资料没写，模型自己补了句"退款需缴纳手续费"
  —— W2 的优化全是对着这三病下药
```

## 2. 核心概念（中英对照+大白话）

| 英文 | 中文 | 大白话解释 |
|------|------|-----------|
| Ingestion Pipeline | 入库链路 | 切分+嵌入+入库（文档进来时跑一次） |
| Query Pipeline | 查询链路 | 检索+组装+生成（每次问答都跑） |
| Naive RAG | 朴素 RAG | 最直连的 v0（三大病俱全，但必须先有它） |
| Top-K | 取前 K | 检索返回相似度最高的 K 块（3~5 起步） |
| Prompt Assembly | Prompt 组装 | 资料+问题按模板拼装（注入前最后一步） |
| Framework-free | 无框架 | 先手写再学框架（LangChain4j 等），知其所以然 |

## 3. 动手实操：组装 mini-rag.ps1

### 3.1 脚本骨架（四步注释齐全，跑通为准）

```powershell
# mini-rag.ps1 —— 人生第一个 RAG（无框架版）
# ===== 入库部分（跑一次）=====
# Step1 切分：读 test-doc.txt，按 day04 的递归法切成块（数组 $chunks）
# Step2 嵌入：foreach ($c in $chunks) {
#   调 http://localhost:11434/api/embeddings 得 768 维向量 → 存 PGVector }
# ===== 查询部分（每次问答）=====
# Step3 检索：
$q = "退款多久到账"                                   # 用户问题
$qv = (嵌入 $q)                                       # 问题也变坐标
$hits = (PGVector 查最近 3 块)                        # day03 的 <=> 查询
# Step4 组装+生成（Prompt 模板先最简版，day06 换正式版）：
$prompt = "根据以下资料回答问题。资料：`n$($hits -join "`n")`n问题：$q"
# → 调 M13 day08 的 /v1/chat/completions → 输出答案
```

## 4. 面试连接

**Q：讲一下 RAG 的完整链路？（基本功题，要求 1 分钟画得出）**
> 两条链路。入库链路：文档解析清洗后切分成块，每块用嵌入模型转成向量存进向量库——切分我会按文档结构走，验收标准是每块独立可读。查询链路：用户问题同样嵌入成向量，在库里做近邻检索取 Top3，把检索到的资料和问题按模板组装进 Prompt，让模型有据生成，答案要求带引用标注。我强调两点工程细节：一、入库是一次性的但更新是常态，所以入库要按文档 ID 幂等，方便增量更新；二、朴素 RAG 有三大病——检索不准、上下文污染、生成幻觉，我们第一次跑通时就全碰到了，比如问题换个说法检索就空手而归，资料里没写的内容模型自己编手续费。所以我后续的优化都是对着这三病下药：混合检索加查询改写治检索，重排治污染，有据生成加拒答治幻觉。先跑通再优化，每个病都有实验现场，这是我认为正确的学习路径也是正确的工程路径。

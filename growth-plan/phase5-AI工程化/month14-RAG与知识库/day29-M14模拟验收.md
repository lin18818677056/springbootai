# Day 29 · M14 模拟验收：五轮 30 问

> **今日目标**：闭卷口头验收本月 30 天。五轮共 30 问（每轮对准一周+一轮综合压轴）；白板三件套限时画/写；按 L1~L4 判级定下一步。
> **时长**：问答 2.5h / 白板 0.5h / 输出 0.5h
> **今日产出**：30 问作答记录（✓/○/×）+ 三件套照片 + 判级结论
> **规矩**：M13 day29 同款——说给录音笔，不许看笔记；卡壳标 ○，答错标 ×。

## 1. 验收规则

```
每问 90 秒内开口，先给结论再展开（面试铁律）。
30 问里 ≥24 问流畅 = 过线；白板三件套每件限时 5 分钟。
验收后：○ 和 × 的题翻回对应 day 重读，day30 复盘时二次清账。
```

## 2. 第一轮 · 世界观（W1，6 问）

```
1. RAG 和微调、长上下文，私有知识场景怎么选？为什么？
   （考官想听：三笔账——窗口/成本差百倍/中间遗忘+决策卡）
2. Embedding 到底在做什么？它的两个软肋各举一个翻车例子。
   （文字→坐标；否定词 0.9 / 专有名词）
3. 余弦相似度比的是什么？为什么不用欧氏距离？
   （比方向不比长短；文本关注"意思像不像"）
4. 向量库解决的真问题是什么？暴力 kNN 有什么问题？
   （从 O(n) 到 ANN"快递分拣"；30 行 MiniVectorStore 讲起）
5. 切分的验收标准是什么？切坏了会发生什么？
   （每块独立可读；上下文污染/答非所问的根因）
6. 朴素 RAG 三大病是什么？各用什么药？
   （检索不准→混合检索；上下文污染→Rerank/父子块；生成幻觉→三板斧）
```

## 3. 第二轮 · 检索进阶（W2，6 问）

```
7. 你怎么证明"你的检索变好了"？空口无凭怎么办？
   （对拍第六次：30 条考卷五类型+HitRate/MRR 双指标）
8. BM25 和向量检索各强在哪？为什么必须双路？
   （关键词精确匹配 vs 语义泛化；强弱互补表）
9. 两路分数直接加不行吗？RRF 的核心思想是什么？
   （温度加体重=量纲灾难；比名次不比分数；k=60 压头部）
10. 查询改写三种手法各解决什么问题？什么时候不要改写？
    （指代消解/查询扩展/HyDE；简单问题别过度加工）
11. Rerank 为什么放最后一级？它和 RRF 的分工是什么？
    （RRF 管共识，Rerank 管真实相关度；海选 20 精评 5 的成本账）
12. 父子块解决什么问题？检索用谁、喂给模型用谁？
    （小块检得准大块答得全；子块检索、取爹重排）
```

## 4. 第三轮 · 工程化（W3，6 问）

```
13. 入库链路的幂等怎么做的？为什么必须一个事务？
    （三保险：SHA-256 指纹/先删后插/批量嵌入；半新半旧=脏库）
14. 查询链路八步编排里，SSE 三帧是怎么发的？为什么 citation 先发？
    （citation/delta/done；先让用户看见"有据可查"再出字）
15. 引用幻觉怎么防？为什么"模型说不算，代码说了算"？
    （CitationValidator：编号存在性校验+假标注剥除；宁缺毋假）
16. 权限过滤为什么必须在检索前做？检索后过滤有什么问题？
    （先泄密再拦截；SQL where+默认拒绝；提示注入在 SQL 层免疫）
17. 客户端"安全带五件套"是哪五件？只重试哪些错误？
    （超时两档/只重试超时+5xx+429/指数退避/fallback 链/usage 计量）
18. 为什么引用校验放在 SSE citation 帧之前而不是之后？
    （先校验再展示；假引用一旦发给用户就是事故）
```

## 5. 第四轮 · 生产化（W4，6 问）

```
19. RAGAS 四指标各盯哪个环节？Faithfulness 低了按什么顺序排查？
    （忠实度→生成侧；排查决策树：先 Prompt 后检索再切分）
20. 知识过期为什么叫"无声过期"？三道防线是什么？
    （不报错但答案在说旧话；自动同步/资料时间可见/周抽检+短 TTL）
21. QA 缓存有哪三个坑？语义缓存阈值为什么 ≥0.97？
    （权限 key/拒答不缓存/TTL 分级；否定词 0.9 的缓存版翻车）
22. 拒答率为什么是"最灵敏的信号"？它升高说明什么？
    （检索坏了或知识库缺内容；单次是特性批量是事故）
23. 压测为什么必须分段？开缓存和关缓存各代表什么？
    （检索段瓶颈 DB 连接池/生成段瓶颈算力；生产画像 vs 最坏容量线）
24. 三预案里你认为最隐蔽的是哪个？演练挖出了什么真 bug？
    （知识过期；更新链路刷了库但缓存还有旧答案→入库后联动清缓存）
```

## 6. 第五轮 · 综合压轴（6 问）

```
25. 把你这个项目从 0 到 1 讲 3 分钟（结论先行）。
26. 优化台账五行，讲其中一行完整的"量→改→量"故事。
    （推荐 RRF 行或 Rerank 行：基线数字→改了什么→对拍结果）
27. 这个项目和 M13 的项目三是什么关系？架构上怎么接的？
    （分类器复用做意图路由；客户端/模板库/日报直接继承）
28. 上线验收你是怎么给结论的？哪一条不满足就不放行？
    （六项：预案点火/降级有痕/降级带标注/红线告警/缓存联动/限流线）
29. 如果知识库涨到 10 万文档，你的架构哪里先崩？怎么改？
    （PGVector 索引与连接池先顶不住→分库/专用向量库+冷热分层；
     能主动讲瓶颈推演=加分项）
30. 这个月你最大的一个"诚实认知"是什么？
    （参考方向：检索优化没有银弹，每一步都要考卷说话；
     或"能跑"和"能管"之间差一整个 W4）
```

# 第 15 月：Agent（智能体）进阶、模型部署与 AI 应用架构

> **本月一句话目标**：从"会做单个 AI 功能"升级为"会设计 AI 应用整体架构"：多 Agent 协作、MCP 生态、私有化部署与推理优化、AI 网关与安全治理。本阶段（阶段五）收官，你将具备大厂"AI 应用架构师"的完整能力拼图。**详细教程配合阅读 `ai-learning/05~07`。**

## 本月目标与验收标准

- [ ] 讲清 Agent 架构三件套：规划（Planning）、记忆（Memory）、工具（Tools），并实现一个多 Agent 协作 Demo
- [ ] 深入 MCP 协议（Resources/Prompts/Tools 三原语、采样 Sampling），开发一个有业务价值的 MCP Server
- [ ] 掌握私有化部署：Ollama/vLLM（高吞吐推理引擎）、量化（GGUF/AWQ）、GPU 选型与成本估算
- [ ] 设计 AI 应用架构：AI 网关（限流/计费/多模型路由/降级）、评测与监控、灰度发布
- [ ] 完成"AI 智能助理"综合项目（整合 RAG + Agent + 多模型）并演示
- [ ] 阶段五毕业：达成 README 里程碑 M5

## 每日计划

### 第 1 周：Agent 架构进阶

| 日 | 主题 | 知识点（中英对照） | 实战任务 | 验收标准 |
|----|------|-------------------|---------|---------|
| D1 | Agent 本质与范式 | Agent = LLM（大脑）+ 记忆 + 工具 + 规划循环；四大范式对比：ReAct（推理行动）/Plan-and-Execute（先规划后执行）/Reflexion（反思改进）/Multi-Agent（多智能体协作） | 画出四种范式流程图 | 能按任务复杂度选范式 |
| D2 | 记忆系统 | 短期记忆（对话窗口）/长期记忆（向量库+数据库）、记忆写入策略（摘要压缩/重要性打分）、个性化记忆（用户偏好沉淀） | 给项目四加上长期记忆（跨会话记住用户偏好） | 第二次会话能体现记忆 |
| D3 | 多 Agent 协作 | 协作拓扑：主管模式（Supervisor：主 Agent 分发）、流水线（Pipeline）、辩论式（Debate）；框架认知：LangGraph（图编排）/Spring AI Agentic 能力；Anthropic《Building Effective Agents》思想（能简单就别复杂） | 实现"研究助理"双 Agent（检索员+撰写员，Supervisor 协调） | 任务拆分与结果汇总正确 |
| D4 | 工具设计工程化 | 工具粒度设计（太细导致选择困难/太粗不够灵活）、工具描述（Description 即 Prompt，决定调用准确率）、参数校验与超时、工具结果截断 | 重构项目四的工具集（≤8 个高内聚工具） | 工具调用准确率 ≥ 90%（30 条用例） |
| D5 | 可靠性与护栏 | Agent 失控场景（死循环/越权调用/幻觉工具参数）、护栏（Guardrails）：白名单/参数校验/预算限制（Token 预算）/人工介入（Human-in-the-Loop 人在回路） | 实现 4 层护栏并演示拦截 | 每层护栏有触发案例 |
| D6 | 可观测与评估 | Agent 轨迹（Trace）记录（每步 Thought/Action/Observation 落库）、轨迹评估（任务完成率/轮数/成本）、失败归因（选错工具/参数错/推理错） | 实现 Agent 轨迹面板（简单页面即可） | 20 个任务完成率出数 |
| D7 | 周复盘 | Agent 专题串讲 | 周记 + 《Agent 落地 Checklist》 | 达成周验收 |

### 第 2 周：MCP 生态与私有化部署

| 日 | 主题 | 知识点（中英对照） | 实战任务 | 验收标准 |
|----|------|-------------------|---------|---------|
| D1 | MCP 协议深入 | 三大原语：Tools（工具）/Resources（资源：只读数据）/Prompts（提示模板）、传输层（STDIO 本地 / Streamable HTTP 远程）、能力协商（Capability Negotiation）与版本、Sampling（服务端反向请求 LLM） | 画出 MCP 完整时序图（初始化/列工具/调工具） | 协议细节可应对追问 |
| D2 | MCP Server 开发 | Spring AI MCP Server 注解式开发（@McpTool）、工具文档化、错误码与重试语义 | 开发"公司 IT 服务台"MCP Server（查工单/重置密码/查知识库） | 标准 MCP Client 直连可用 |
| D3 | MCP 生态与安全 | MCP 生态现状（官方仓库/社区 Server）、安全风险（恶意 Server/工具描述注入/越权数据访问）、企业接入治理（审批/沙箱/最小权限） | 输出《企业 MCP 接入规范 v1》 | 规范含 5 条安全红线 |
| D4 | 推理引擎与 vLLM | 推理服务化：Ollama（个人级）vs vLLM（生产级：PagedAttention 分页注意力显存管理、Continuous Batching 连续批处理）、吞吐与并发对比 | 用 vLLM 部署一个 7B 开源模型并压测 | 有 Ollama vs vLLM 吞吐对比数据 |
| D5 | 量化与硬件 | 量化（Quantization：FP16→INT8→INT4，精度-资源权衡、GGUF/AWQ/GPTQ 格式）、硬件估算（7B Q4 ≈ 5GB、70B 需多卡 A100/4090 集群）、国产芯片生态认知 | 本机量化部署对比（Q4 vs Q8 质量与速度） | 有质量抽检 + 速度对比 |
| D6 | 混合模型路由 | 模型路由策略（简单问题小模型/复杂问题大模型、成本导向路由）、降级链路（主模型故障切备用）、本地+云端混合（隐私数据本地） | 实现规则+分类器两级路由 | 平均成本下降 ≥ 30% 有数据 |
| D7 | 周复盘 | MCP+部署串讲 | 周记 + 《私有化部署决策树》（数据敏感度/预算/并发 → 方案） | 达成周验收 |

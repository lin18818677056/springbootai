# month13 · 大模型基础与 Prompt：AI 时代的 Java 架构师第一课

> **本月一句话**：从"调用过 API 的人"升级为"能对模型输出的正确性、成本、安全负责的人"——用 12 个月攒下的工程方法论（对拍/幂等/倒推/预案）驯服一个概率系统。
> **前置**：M12 交接卡两道思考题（上下文窗口 vs Flink 状态 / temperature 随机性 vs 实离差异）。
> **参考教程**：`ai-learning/01-大模型基础原理.md`、`02-Prompt工程.md`（本月为主教材，day 内有对照）。

## 一、本月 8 条验收标准（day30 逐条对账）

```
1. 用"下一个词预测"讲清 LLM 本质，并推出四个工程结论（概率/无记忆/会编造/知识截止）
2. Token/上下文窗口/成本估算三件事脱口而出（1 汉字≈1~2 token；注意力平方增长）
3. 至少完成一种"真调用"：Ollama 本地模型 或 OpenAI 兼容 API（curl 即可）
4. Prompt 四件套+Few-shot+CoT 成体系，产出个人《Prompt 模板库 v1》（≥8 个模板）
5. 结构化输出+流式输出亲手跑通（JSON 能被程序解析、SSE 打字机效果见过）
6. 项目周三件套：工单分类器/多轮记忆/审核流水线（全部有实验记录）
7. 评测体系上线：50 条业务评测集+盲评打分（对拍思想第五次上场）
8. 模型选型五维法+《AI 应用架构总图》（网关/缓存/评测/降级）
```

## 三、环境准备（正路径+降级路径，诚实原则不变）

```
正路径①（推荐，全本地零成本）：Ollama
  官网下载安装 → ollama run qwen2.5:7b（7B 模型，16G 内存可跑）
  显存/内存不足 → 换更小模型：qwen2.5:3b 或 qwen2.5:1.5b（效果打折但流程不变）
正路径②（有 API Key 时）：OpenAI 兼容接口
  DeepSeek/通义/OpenAI 均可——本月脚本全用 curl，兼容协议一处学到处用
降级路径（两者都没有）：不影响主线！
  概念周：教程里的概率分布示例手工推演
  Prompt 周：模板照样写，"人肉模拟模型输出"对照检查
  诚实记录：day30 未达清单里标记，环境就绪后补实验
```

## 五、本月心法

```
别把大模型当玄学，把它当"一个很会说话但会胡说的实习生"：
  ① 它是概率系统——输出不保证一致，所以要评测兜底（对拍思想）
  ② 它没有记忆——上下文窗口就是它的全部记忆，要省着用（成本意识）
  ③ 它会编造——不知道的事也会顺着说，所以要外挂知识（RAG）
  ④ Prompt 是新世纪的 SQL——写得好坏直接决定产出质量，值得当正经工程对待
```

## 4. 博客⑨：《大模型会胡说，工程师怎么把它关进笼子》

```
大纲（通俗向，目标读者：没用过 AI API 的后端同学）：
  1. 开场：它一本正经地告诉我"退款已到账"——其实我根本没退款
     （幻觉案例开场，比讲 Transformer 抓人）
  2. 先懂它：文字接龙本质 → 四个工程结论（概率/无记忆/会编造/知识截止）
     ——结论不玄，全是接龙的自然后果
  3. 四道防线（文章主体，每道配真实实验）：
     溯源（给引用让它抄）/ 注入（检索来的资料喂进上下文=下月 RAG 预告）/
     校验（结构化输出+防御链）/ 兜底（降级链+人工队列）
  4. 管行为：Prompt 注入=SQL 注入的亲戚；建议权红线（模型不碰执行）
  5. 管成本：token 记账+三层杠杆（缓存/精简/路由）
  6. 收尾金句：大模型不是黑魔法，是"很会说话但会胡说的实习生"——
     实习生要带教，模型要工程化。配图：day25 五层架构总图
发布：掘金/公众号二选一，标题 A/B 各发一版看打开率。
```

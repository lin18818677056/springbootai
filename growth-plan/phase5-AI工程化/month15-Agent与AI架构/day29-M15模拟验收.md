# Day 29 · M15 模拟验收：五轮 30 问

> **今日目标**：闭卷口头验收本月 30 天。五轮共 30 问（每轮对准一周+一轮综合压轴）；白板三件套限时画/写；按 L1~L4 判级定下一步。
> **时长**：问答 2.5h / 白板 0.5h / 输出 0.5h
> **今日产出**：30 问作答记录（✓/○/×）+ 三件套照片 + 判级结论
> **规矩**：M13/M14 同款——说给录音笔，不许看笔记；卡壳标 ○，答错标 ×。

## 1. 验收规则

```
每问 90 秒内开口，先给结论再展开（面试铁律）。
30 问里 ≥24 问流畅 = 过线；白板三件套每件限时 5 分钟。
验收后：○ 和 × 的题翻回对应 day 重读，day30 复盘时二次清账。
```

## 2. 第一轮 · 世界观与点菜（W1，6 问）

```
1. RAG 和 Agent 的边界？三种翻车现场各用什么解？
   （考官想听：决策卡五边界+"能用固定流水线别上循环"）
2. Agent 循环四步？为什么说执行权永远在应用侧？
   （while+刹车；"实习生打申请，批不批代码说了算"）
3. Function Calling 的本质？模型真的会调用函数吗？
   （点菜不炒菜；原生 tools vs 手写 JSON 协议）
4. 三道闸各防什么？身份从哪来？
   （参数/归属/审计；CurrentUser.id() 不信模型自述）
5. 工具描述三要素？举一个"改描述修 bug"的实验。
   （何时用+负向约束+例子；误触发数据对比）
6. 工具考卷为什么要有陷阱题？两个指标怎么一起看？
   （手痒率；正确率+误触发率）
```

## 3. 第二轮 · 循环与安全（W2，6 问）

```
7. ReAct 的 R 是什么？思考显式化的收益和代价？
   （可调试/更准/自愈；token+事后合理化）
8. ReAct 和 Plan-and-Execute 怎么选？为什么"计划也要审"？
   （路径可预期性；计划也是模型出的会离谱）
9. 多跳的钥匙链是什么？三道防线？
   （上跳输出=下跳输入；跳数/预算/卡壳）
10. 死循环三种成因？三层刹车各治什么？
    （磨洋工/踢皮球/自我怀疑；轮次/预算/重复检测）
11. 幻觉参数三分类？治理优先级怎么排？
    （缺失/编造/越界；描述→结构化错误自愈→转人工）
12. 两级审批流怎么设计？"模型说用户同意了"为什么不作数？
    （挂起-人工批-代码执行；审批状态在应用侧）
```

## 4. 第三轮 · 生态与协作（W3，6 问）

```
13. MCP 解决什么问题？定位答法（背）。
    （M×N→M+N；"Function Calling 是能力机制，MCP 是生态协议，
      安全模型不变"）
14. 三类能力的控制权差异？各举项目一例。
    （模型点/应用配/用户选；kbSearch/政策原文/多跳模板）
15. 把内部工具 MCP 化的三个坑？
    （描述偷懒/身份传递/资源投毒间接注入）
16. 电视机类比讲三角架构？双传输怎么选？
    （Host/HDMI/机顶盒；stdio 本地 vs HTTP 团队共享）
17. 主管模式的纪律？拆分的正当理由？
    （主拆+合不碰业务工具；专业互斥/上下文互扰/可并行）
18. 四问决策卡是什么？举证责任在谁？
    （默认不拆；四问三否就不拆）
```

## 5. 第四轮 · 生产化（W4，6 问）

```
19. 项目五三条架构决策？各自"为什么"？
    （复用检索器/路由前置/MCP 划边界）
20. 留痕三原则？留痕怎么帮你破案？
    （全量/结构化/可回放；描述 bug 定位实验）
21. Agent 压测和 RAG 压测三点不同？成本为什么超线性？
    （轮次分桶/TTFT/轮次乘数；上下文膨胀）
22. 上线检查单五项？"最坏损失"怎么答？
    （迭代/权限/预算/审计/人工；三四轮 token+转人工）
23. 三预案演练挖出了什么真 bug？
    （会话活性：驳回回填时 SSE 已关闭→resume 查活性+IM 补送）
24. 日报六指标 Agent 版？为什么熔断率是第一信号灯？
    （传统三数+熔断/轮次/分工具成功率+周抽检；最灵敏异动信号）
```

## 6. 第五轮 · 综合压轴（6 问）

```
25. 项目五从 0 到 1 讲 3 分钟（结论先行）。
26. 讲一条完整的"量→改→量"台账（推荐：描述优化行或刹车行）。
27. 这个项目和 M13/M14 项目什么关系？哪些直接复用？
    （分类器路由/检索器工具化/客户端五件套/日报日报链）
28. 模型抽风连调 20 次，最坏损失？三词各自的证据？
    （可控=刹车+只读；可解释=留痕回放；可回放=trace+审计）
29. 如果流量涨 10 倍，架构哪里先崩？怎么改？
    （单卡 Ollama 排队→多实例+路由分级；trace 异步写+采样；
     能主动讲瓶颈推演=加分项）
30. 这个月你最大的一个"诚实认知"是什么？
    （参考方向：Agent 的大部分"智能问题"其实是"工具设计问题"；
     或"默认不拆"比"会拆"更难学）
```

② Agent 安全防御体系图：三不信任→三道闸→四层纵深→人工闸

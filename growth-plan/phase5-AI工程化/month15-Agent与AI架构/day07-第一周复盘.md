## 1. 六天串讲（一条线）

```
day01 为什么需要 Agent：
  三种翻车现场（懒得用/办事问题/一步不够）→ RAG 管书里有没有，
  Agent 管系统能不能办 → 决策卡五行边界（能用固定流水线别上循环）
day02 Agent 的本质：
  while 循环（思考→行动→观察）+ 三不信任（身份/参数/代价）
  → "模型是会打字的实习生，它的输出是申请，批不批代码说了算"
day03 Function Calling 第一课：
  模型只点菜不炒菜——本质是约定输出格式；两条路径（原生 tools/
  手写 JSON 协议）；IntentParser 三原则（容错/白名单/参数不可信）
day04 单工具闭环：
  三道闸（参数校验/归属校验/审计）+ 结构化错误（错误信息是给
  模型看的输入）+ 三个对抗实验（幻觉参数/越权/不存在单号）
day05 工具描述与参数设计：
  五条军规；描述=写给模型的使用说明书（何时用+负向约束+例子）；
  对照实验证明"改描述就能修 bug"；动态挂载控数量
day06 多工具与选择正确率：
  对拍第七次上场；20 题五类型考卷；正确率+误触发率一起看；
  v0 基线入台账（本月台账开张）
```

# Java 架构师成长之路（7年后端 → 阿里 P8-P9 水平 + AI 技能）

> **你的现状**：7 年 Java 后端经验，日常能完成业务开发，但对底层原理、分布式架构、技术纵深掌握不深（自评中下水平）。
> **目标定位**：18 个月后达到互联网一线大厂 **P8（高级专家/架构师）** 水平，具备冲击 **P9（资深专家）** 的视野，并掌握 **AI 工程化** 能力（2026 年架构师标配）。
> **学习环境**：本机已有 `springbootai` 项目（Java 25 + Spring Boot + Gradle），所有实战代码都在此工作区展开。

## 一、先看清终点：P5-P9 职级能力对照表

| 职级 | 头衔（Title） | 能力画像（画像 = Profile） | 典型表现 |
|------|--------------|---------------------------|---------|
| P5 | 工程师 | 在指导下完成模块开发 | 会用框架，不懂原理 |
| P6 | 高级工程师 | 独立负责一个模块/小型系统 | 熟练 CRUD + 中间件使用，能排查常见问题 |
| P7 | 技术专家（T） | 独立负责一个子系统/中型系统，能攻坚复杂技术问题 | 懂 JVM 调优、并发原理、中间件原理，能做性能优化，指导 P5-P6 |
| **P8** | **高级专家 / 架构师** | **负责一个技术领域（Domain）的架构**，主导技术选型、跨团队推动、带 5-15 人团队 | **能设计高并发高可用系统、输出架构方案、主导架构评审、推动技术债治理、有 AI 工程落地经验** |
| **P9** | **资深专家** | **负责事业部级技术战略**，定义技术方向，有行业影响力 | **跨域架构（交易+数据+AI）、技术布道、专利/开源影响力、组织级技术决策** |

> **你的差距诊断（中下水平 7 年后端典型症状）**：
> 1. 原理层：JVM/并发/网络只会"背八股"，没有排查线上问题的肌肉记忆（肌肉记忆 = Muscle Memory，指不假思索即可完成的操作能力）。
> 2. 架构层：没有独立设计过万级 QPS（Queries Per Second，每秒查询数）系统，方案停留在"抄别人"。
> 3. 广度层：大数据（Data Platform）几乎空白，AI 只停留在调用 API。
> 4. 影响力层：没有技术输出（博客/分享/开源），简历讲不出有深度的项目故事。
>
> 本计划逐条对应消灭上述差距。

## 四、学习方法论（比计划本身更重要）

1. **费曼技巧（Feynman Technique）**：每学完一个知识点，用"讲给 5 年经验同事听"的口吻写一篇 500 字笔记。讲不清 = 没学会。
2. **源码三遍法**：
   - 第一遍：跑 Demo（演示程序），看输入输出；
   - 第二遍：带问题读主线流程（如 RocketMQ 一条消息从 Producer 到 Consumer 的完整路径）；
   - 第三遍：画时序图/架构图，输出博客。
3. **问题驱动**：每个知识点绑定一个线上问题场景。例如学 Redis 缓存击穿时，问自己"如果我是值班人，半夜缓存雪崩了怎么办？"
4. **输出倒逼输入**：每月至少 2 篇博客（掘金/知乎/公众号），阶段结束做 1 次公开分享（组内或线上）。
5. **面试导向但不背题**：所有八股题必须能落地到"我做过的一个案例"，否则视为未掌握。

## 七、高频术语中英对照表（本计划通用）

| 英文 | 中文 | 说明 |
|------|------|------|
| QPS (Queries Per Second) | 每秒查询数 | 衡量系统吞吐的核心指标 |
| TPS (Transactions Per Second) | 每秒事务数 | 衡量写入/交易吞吐 |
| RT (Response Time) | 响应时间 | P99 = 99% 请求的最大响应时间 |
| SLA (Service Level Agreement) | 服务等级协议 | 常见承诺：可用性 99.99%（全年故障 ≤ 52.6 分钟） |
| SRE (Site Reliability Engineering) | 站点可靠性工程 | 稳定性保障的方法论 |
| HA (High Availability) | 高可用 | 通过冗余消除单点故障 |
| SLB (Server Load Balancer) | 服务端负载均衡 | |
| SLO (Service Level Objective) | 服务等级目标 | SLA 的内部量化指标 |
| PoC (Proof of Concept) | 概念验证 | 技术选型前的小规模验证 |
| Tech Radar | 技术雷达 | 组织级技术选型全景图 |
| RFC (Request For Comments) | 方案征求意见稿 | 大厂标准的技术方案评审载体 |
| LLM (Large Language Model) | 大语言模型 | AI 阶段核心概念 |

# Month10 · Hadoop 与 Hive（大数据第一月）

> **本月一句话**：用 Java 后端最熟悉的方式入门大数据——先搞懂"几十亿行数据到底怎么存"（HDFS）、"一台机器算不动怎么办"（MapReduce 分工干活）、"这么多机器谁管谁"（YARN），最后用 Hive 写 SQL 就能分析海量数据，亲手搭一套电商数仓。**所有概念都先用大白话和生活类比讲一遍，再上专业术语。**

## 本月项目说明

- **写给中下水平 Java 工程师的大数据入门**：不堆砌名词。每个概念出场顺序是——先说"它解决什么问题"→ 再打个比方 → 最后才是术语和命令。比如 NameNode 就是"仓库总台账"，DataNode 就是"仓库货架"，账本丢了货再多也找不到。
- **主线项目：电商行为数仓**（Docker 单机版）。从原始日志一层层加工成"老板能直接看的大屏数字"，走完 ODS→DWD→DWS→ADS 四层——就像厨房从"进货"到"洗菜"到"半成品"到"装盘上桌"。
- **环境**：Docker Desktop 一键拉起 Hadoop（HDFS+YARN）+ Hive（MySQL 存元数据）；配合 `big-data/01~03` 三篇教程文档。
- **与前面月份的关系**：M8 学的"读写分离、数据对账、状态机"思想在大数据域全部复用——本月你会反复看到"原来那个知识在这里又出现了"。

## 验收标准（day30 逐条对账）

1. **讲清 HDFS**：NameNode/DataNode 分工、Block 128MB 与三副本、读写流程、小文件为什么是灾难（白板画图可查）
2. **讲清 YARN**：RM/AM/NM 三角色分工、三种调度器区别、能给公司设计队列方案
3. **Hive 实操**：内外部表选型、分区裁剪生效（EXPLAIN 验证）、窗口函数 10 题全过
4. **数仓建模**：星型模型设计、SCD 拉链表、四层分工各一句话讲清
5. **数据倾斜**：3 种倾斜场景能复现+治理，治理前后耗时对比有数字
6. **数仓项目**：ODS→DWD→DWS→ADS 全链路跑通，ADS 大屏数字可复现；博客 1 篇

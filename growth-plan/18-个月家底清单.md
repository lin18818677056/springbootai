## 六、30 秒取件指南（三个典型场景）

```
场景 A：明晚有一场 Java 面试
  ① 打开 M18 README 课程表 → 按"深挖面/设计面/管理面"对号入座
  ② 对应日的前一晚：day12（追问话术）+ day16（弱点地图降级话术）
  ③ 系统设计面加练：day08 六步法 + 三大骨架卡（day09/10/11）

场景 B：工作中线上出问题（CPU 飙高/内存泄漏/GC 频繁）
  ① M1 day13（GC 日志）→ 先定位是哪种问题
  ② M1 day01~day03（Arthas/MAT 实操）→ 上手排查
  ③ 定位到代码层 → M16 源码三部曲找机制原因

场景 C：写博客/做分享找素材
  ① 本清单第二节"月度资产地图"按主题锁定月份
  ② 进该月 README → 找"本月产出清单"章节 → 挑有数据的那篇
  ③ 记住写作公式：实验 + 数据 + 边界（这套文档全部长这样）
```


**Q：你说学了一个月，最让你改观的认知是什么？（软性题，考察真学习）**
> 示范回答（从本月提炼）："以前以为高并发靠'更快的数据库'，现在理解是'分层拦截'——DB 只该承受它该承受的流量（秒杀 DB 只见 1/500 请求）；以前以为分布式锁是万能的，现在理解'锁是最后的手段'——Lua 原子、唯一索引、条件更新能解决的都不用锁；以前背'缓存三大问题'的口诀，现在是复现过的实验数据和理解到'失效代价集中转移'这个本质。"（真实认知变化无法伪造，这题答好=前面的学习都可信）

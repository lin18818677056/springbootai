## 4. 面试连接（模拟的"追问链"训练）

**追问链示例 A（从 17 题延伸，面试官的真实追问路径）：**
> "分布式锁怎么实现？" → "看门狗如果业务执行到一半进程挂了怎么办？"
> （答：锁最终过期释放，业务侧幂等兜底——锁不承诺安全只承诺效率）
> → "那 RedLock 呢？" → "为什么 Martin 说它不安全？" → "你的选型建议？"
> 训练法：每个主问题自己往下追问 2 层，答不出就是薄弱区。

**追问链示例 B（从 28 题延伸）：**
> "怎么不超卖？" → "Redis 扣了但 DB 扣失败怎么办？"
> （答：事务消息保证消息必达；消费端重试+对账）
> → "消息重复消费呢？"（三层幂等）→ "Redis 幂等锁也失效了呢？"
> （唯一索引兜底——层层递进的设计的意义就是每层失效都有下一层）

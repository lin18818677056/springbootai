# AI 学习教程（AI Learning Path）

> **定位**：面向 Java 后端/架构师的 AI 工程化教程——目标不是训练模型，而是**把大模型用成生产力**：应用开发（Spring AI）、RAG（检索增强生成）、Agent（智能体）、部署与架构。这是 P8-P9 招聘 JD（职位描述）里出现频率最高的 AI 能力清单。
> **学习顺序**：01 → 07 顺序阅读，配合 `../practice-projects/04-rag-knowledge-base/` 实战项目食用。
> **对应成长计划**：`../growth-plan/phase5-AI工程化/`（第 13-15 个月）。

## Java 工程师学 AI 的定位（先想清楚再学）

| 不要陷进去的（研究型） | 要拿下的（工程型） |
|----------------------|------------------|
| 手写 Transformer 反向传播 | 懂 Transformer 原理与选型指标 |
| 训练/预训练大模型 | RAG、微调选型、评估体系 |
| 数学推导（注意力公式的每一步） | 会调模型 API、懂参数含义与成本 |
| 发论文 | 把 AI 变成业务系统的稳定组件 |

**一句话定位**："我是 AI 应用的架构师与工程师——模型是供应商提供的算力组件，我的价值在应用架构、数据链路、成本与安全。"

## 学习路线（3 个月节奏）

```
第 1 个月：01 原理 + 02 Prompt + 03 Spring AI  → 能开发基本 AI 应用
第 2 个月：04 RAG（重点，配项目四）            → 能交付企业知识库
第 3 个月：05 Agent + 06 部署 + 07 架构安全     → 能做架构决策
```
